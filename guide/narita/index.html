成田市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、成田市の公式ページをもとにまとめました。

2026年10月31日に成田市の公式ページで確認・料金や日数は目安です

成田市の粗大ごみは、申し込めば無料で収集されます。1世帯1回3点までで、申し込みは成田富里いずみ清掃工場への電話だけです。家庭のごみは、いずみ清掃工場とリサイクルプラザへ無料で持ち込むこともできます（成田市の公式ページより）。

成田市のポイント
  • 対象：指定ごみ袋に入らない大きさのごみ
  • 料金：無料（1世帯1回3点まで）
  • 申し込み：成田富里いずみ清掃工場へ電話（平日 8:30〜17:15）。インターネット受付の案内なし
  • 出し方：指定された日の朝8時30分までに、ごみ集積所へ
  • 持ち込み：いずみ清掃工場（木製家具など）・リサイクルプラザ（金属製家具など）へ。家庭のごみは手数料なし

申し込み方法

  • 電話：成田富里いずみ清掃工場 0476-36-1689（月〜金曜 8:30〜17:15、祝日・12月29日〜1月3日は休み）

インターネットでの申し込みは、市のページに案内がありません。1世帯につき1回3点までです。申し込みが集中してつながりにくいことがあり、「接続器が故障している」という案内が流れても故障ではないので、時間をおいてかけ直してください。成田市リサイクルプラザでは粗大ごみの申し込みは受け付けていません。

料金の目安と払い方

出し方料金
粗大ごみの収集（1世帯1回3点まで）無料
家庭のごみの持ち込み（いずみ清掃工場・リサイクルプラザ）無料

料金は目安です。2026年10月31日に成田市 粗大ごみの出し方と搬入受付票のページで確認。処理券は使いません。事業所から出るごみは有料です。

出し方

  • 紙に「粗大ごみ申し込み済み」をカタカナで書き、申し込んだ人の名字も書いて、見やすいところに貼ります。
  • 指定された日の朝8時30分までに、ごみ集積所へ出します。
  • 自転車は「再生品利用承諾書」をフレームに貼ります。承諾書は市役所5階のクリーン推進課・各公民館・各支所でもらえるほか、市のページから印刷できます。
  • きずや色あせがなく、ネジや部品がそろった大型の木製家具は、成田市リサイクルプラザ（0476-36-1000）に相談できます。

出せない物と家電4品目

  • テレビ、エアコン、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • 事業活動から出る産業廃棄物

家電4品目は、市では回収しません。買ったお店・買い替えるお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。市内に指定引取場所はありません（市の家電リサイクルのページ）。

急ぐときはいずみ清掃工場・リサイクルプラザへ持ち込む

  • 持ち込み先：成田富里いずみ清掃工場（成田市小泉344-1、0476-36-1689）は可燃ごみと木製の家具類など。成田市リサイクルプラザ（同じ住所、0476-36-1000）は不燃ごみ・資源物と、金属製の家具類・小型家電など。
  • 受付：月〜土曜（祝日も可、日曜は休み）8:30〜12:00、13:00〜16:30。終わる30分前までに受付をすませます。リサイクルプラザの受付時間は、持ち込む前に市のページで確かめてください。
  • 料金：家庭のごみは手数料なし（事業所のごみは有料）。
  • 事前の連絡：土曜・祝日に持ち込むときは前日までに連絡します。軽トラック1台以上の多量のごみや、トラックで運ぶときも、先に各施設へ連絡します。
  • 持ち物と決まり：成田市に住む本人が自分で運転して持ち込みます。運転免許証と「搬入受付票」（市のページから印刷、計量の受付にも置いてあります）を出します。住所が確かめられないと断られます。本人が運転できないときは先に連絡し、ごみの出どころや親族関係を示す書類が要ることがあります。
  • 年末は混み合い、1時間以上待つことがあります。

成田市に引っ越してきた人へ

成田市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 軽トラック1台以上の多量のごみを持ち込むときは、事前にいずみ清掃工場やリサイクルプラザへ連絡します。
  • 持ち込めるのは成田市に住む本人が自分で運転して運ぶ家庭のごみで、運転免許証と搬入受付票を出します。住所が確かめられないと断られます。
  • 家庭のごみの持ち込みに手数料はかかりません。
  • 粗大ごみの収集は1世帯1回3点までです。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。成田市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 受付に電話して、早い収集日がないか聞く
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

成田市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、成田市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
