釧路市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、釧路市の公式ページをもとにまとめました。

2026年10月31日に釧路市の公式ページで確認・料金や日数は目安です

釧路市では、いちばん大きい指定ごみ袋（40リットル）に入らない物が粗大ごみです。手数料は1点392円の処理券1種類で、釧路地域は電話のほか電子申請（24時間）でも申し込めます。電子申請では、入力した日から6営業日後以降の収集日を選びます（釧路市の公式ページより）。

釧路市のポイント
  • 対象：40リットルの指定ごみ袋に入らない物（家電4品目を除く）
  • 料金：粗大ごみ処理券1枚392円。原則1点1枚
  • 申し込み：電話（平日）か電子申請（24時間、釧路地域のみ・申込可能リストの品物だけ・1回8点まで）
  • 出し方：収集日の朝9時までに、申し込みで決めた場所へ。立ち会い不要
  • 持ち込み：粗大ごみ処理センター（高山）へ。10kgごとに84円

申し込み方法

  • インターネット（24時間）：釧路市 粗大ごみ電子申請。釧路地域だけで、申込可能リスト（PDF）に載っている品物に限ります。1回8点までです。
  • 電話：釧路地域は釧路市 環境事業課 0154-24-4146（月〜金曜 8:45〜17:15）、阿寒地域は阿寒町行政センター 0154-66-2211、音別地域は音別町行政センター 01547-6-2231

電子申請では、入力した日から数えて6営業日後から40営業日後までの間で、収集日をカレンダーから選びます。リストにない品物は電話で相談します。釧路地域は電話の申し込みのときに収集日と場所が決まります。阿寒・音別地域は電話だけで、あとから収集業者から連絡があります。会社や店で使っていた物は申し込めません。

料金の目安と払い方

品目料金
ソファー・いす（2人掛け以上は1脚、1人掛けは2脚まで）392円
ふとん（2枚ごと）392円
タンス（上下に分かれる物も1棹）392円

料金は目安です。2026年10月31日に釧路市 ごみ袋・粗大ごみ処理券の料金とごみ分別帳（粗大）（PDF）で確認。処理券は1点につき1枚が原則ですが、出す物によって枚数が変わることがあります。

  • 「粗大ごみ処理券」（1枚392円）を、市内と釧路町の一部のスーパー・コンビニなどで買います。申し込んでから買うよう市が案内しています。
  • 処理券に名前を書いて貼ります。「お客様控」は収集が終わるまで取っておきます。払い戻しはできません。

処理券（シール）の買い方

出し方

  • 収集日の朝9時までに、申し込みで決めた場所（自宅前か近くのごみステーションのわき）に、処理券を貼って出します。立ち会いは要りません。
  • 収集日の午後4時までに収集されないときは、環境事業課（0154-24-4146）へ連絡します。
  • リフォーム業者などの工事で出たごみは、粗大ごみに出せません（業者が処理します）。

出せない物と家電4品目

  • テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機、エアコン（家電リサイクル法の対象）
  • 家庭用パソコン、タイヤ、バッテリー、ピアノ、消火器、ガスボンベ、農薬・劇薬など

家電4品目は市では収集しません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。

急ぐときは粗大ごみ処理センターへ持ち込む

  • 持ち込み先：不燃ごみ・粗大ごみは粗大ごみ処理センター（高山）、可燃ごみは釧路広域連合清掃工場（高山）。どちらも計量所で受付をして、帰りにもう一度量って払います。
  • 受付：月〜土曜（祝日を含む）9:00〜16:30（16時までに搬入）、日曜日と12月31日は9:00〜12:30（12時までに搬入）
  • 料金の目安：10kgまで84円。10kgを超える分は10kgごとに84円を足します（消費税相当を含む）。
  • 出し方：分別して透明な袋に入れて持ち込みます。指定ごみ袋や粗大ごみ処理券は使いません。ペットボトル・缶・びんなどの資源物は資源受入ボックスへ無料で出せます。
  • 予約の要否は市のページに書かれていません。持ち込む前に環境事業課 廃棄物対策係（0154-31-4551）で確かめてください。阿寒・音別地域には別の持ち込みの案内があります（阿寒地域・音別地域）。

引越しなどで一度にたくさんのごみが出るときは、市が載せている一般廃棄物処理業者に問い合わせるよう案内されています（家庭のごみを運べるのは許可を受けた業者だけです。引っ越しなどで多量のごみを排出するときは）。持ち込みの準備と持ち物

釧路市に引っ越してきた人へ

釧路市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しなどで多量のごみを出すときは、市のページに載っている一般廃棄物処理業者に問い合わせるよう市が案内しています。
  • 粗大ごみ処理センター（高山）へ自分で持ち込むときは、分別して透明な袋に入れ、指定ごみ袋や処理券は使いません。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。釧路市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

釧路市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、処分代がかからず値段がつくこともあるので、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらい、値段がつかなければ断って釧路市の粗大ごみに切り替えます（どのお店とも提携していません）。

セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどの買取チェーンが出張買取をしています。
