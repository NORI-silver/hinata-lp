自分の市町村の粗大ごみの出し方を調べる方法｜公式ページで見る7つ

記事のない市町村でも、公式ページで7つ確かめれば出し方がわかります。

2026年10月31日更新・料金や日数は目安です

このサイトには、政令市・東京23区・中核市など大きな市区の記事があります（地域ごとの記事の一覧）。お住まいの市町村の記事がないときは、この手順で市町村の公式ページを見れば、出し方がわかります。粗大ごみの決まりは市町村ごとに違うので、ほかの市の記事やまとめサイトの数字をそのまま当てはめないのがいちばん大事です。

1. 市町村の公式ページを見つける

「〇〇町 粗大ごみ」「〇〇市 粗大ごみ 申し込み」で検索します。公式ページかどうかは、アドレスで見分けます。

  • 市町村の公式サイトは、アドレスが lg.jp で終わるもの（例：city.〇〇.lg.jp、town.〇〇.lg.jp）か、city.〇〇.〇〇.jp・town.〇〇.〇〇.jp の形が多いです。
  • 「おいくら」「くらしのマーケット」などのまとめサイトや、不用品回収業者のページは公式ではありません。料金や日数が古かったり、業者への申し込みに誘導されたりします。
  • 小さな町や村では、近くの市町村と一緒に「〇〇広域」「〇〇衛生組合」「〇〇環境組合」がごみを処理していることがあります。持ち込み先は、その組合のページに載っていることが多いです。
  • 市町村が配る「ごみの出し方」「家庭ごみ分別ガイド」（PDFや冊子）にも、粗大ごみの決まりがまとまっています。

2. 公式ページで確かめる7つのこと

確かめること見るポイント
1. 粗大ごみになる大きさ「一辺30cm以上」「指定袋に入らない物」など、市町村で基準が違います（大きさの基準の比べ方）
2. 申し込み方法インターネット・電話・LINEなど。予約がいるか、何日前までか。初めての人は電話だけの市町村もあります
3. 料金と払い方処理券（シール）を買って貼るか、現金か、無料か（処理券の買い方・貼り方）
4. 出す日・時間・場所収集日の朝何時までか、玄関前か集積所か、立ち会いがいるか
5. 収集までの日数申し込みから何日後か。3〜4月は混みやすいので、引越しが決まったらすぐ確かめます
6. 自分で持ち込めるか持ち込み先の施設、予約の要否、料金、本人確認書類（持ち込みの準備と持ち物）
7. 出せない物家電4品目・パソコン・消火器・タイヤ・ピアノなど。家電4品目はどの市町村でも粗大ごみでは出せません（家電リサイクルの料金の目安）

3. ページで見つからないときは電話で聞く

公式ページに書かれていないことは、市町村のごみの担当（「環境課」「清掃課」「ごみ減量推進課」など）か、粗大ごみの受付センターに電話で聞くのが確実です。聞くときは次のように伝えると早く済みます。

  • 「〇月〇日に引越します。それまでに粗大ごみを出したいです」
  • 「出したい物は、ベッド1台・本棚1つ・自転車1台です」（品目と数）
  • 「いちばん早い収集日はいつですか。自分で持ち込むこともできますか」

引越し先の市町村に聞くときは、「前の家から持ってきた家具を出したい」と伝えます。住み始めてから、新しい住所で申し込むのが基本です。

4. 頼るときに気をつけること

  • 家庭のごみを運べるのは、市町村と、市町村が許可した業者だけです。「無料で回収します」という巡回やチラシの業者は、あとで高い料金を請求されることがあります（ぼったくりの実例と見分け方）。
  • まだ使える物は、買取のお店に出すと早く手放せることがあります。
  • 引越しまでに間に合わないときの考え方は間に合わないときの出し方にまとめています。新居へ運ぶ前に新居に持っていくと損する理由も読んでください。

この記事は、市町村ごとの決まりを調べるための手順です。料金・日数・申し込み方法は、かならずお住まいの市町村の公式ページで確かめてください（2026年10月31日更新）。
