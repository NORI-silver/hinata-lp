東大阪市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、東大阪市の公式ページをもとにまとめました。

2026年10月30日に東大阪市の公式ページで確認・料金や日数は目安です

東大阪市では、粗大ごみを「大型ごみ」と呼びます。料金は大きさ（縦・横・奥行きの合計）で決まり、1点400円か800円の2つだけです。1回に10点まで申し込めます（東大阪市の公式ページより）。

東大阪市のポイント
  • 対象：家庭から出る、1辺の長さが30cm以上の可燃物・不燃物
  • 料金：3辺の合計が3m以下は400円、3mを超えると800円（大型ごみ処理券は400円券）
  • 申し込み：大型ごみ受付センターへ電話。インターネットは前に電話で申し込んだことがある人だけ
  • 1回10点まで（畳は2枚まで）。収集日の朝9時までに出す
  • 急ぐとき：水走の東大阪都市清掃施設組合へ予約して持ち込める（10kgにつき90円）

申し込み方法

  • 電話：東大阪市 大型ごみ受付センター 072-962-5374（日曜〜金曜 9:00〜17:00、祝日も受付。土曜・年末年始は休み）。市役所（環境事業課）や環境事業所では受け付けていません。
  • インターネット（2回目から）：東大阪市 大型ごみインターネット受付。使えるのは、平成30年2月以降に電話で申し込んだことがあり、そのあと住所・氏名が変わっていない人です。初めての人、住所や名前が変わった人、前回と違う場所に出したい人は電話で申し込みます。ネットで申し込める品目は決まっていて、一覧にない物は電話です。
  • ファクス：聴覚に障害のある方は 072-962-1673（連絡先を書いて送ります）。

1回の申し込みは10点まで（畳は2枚まで）です。次の申し込みは、収集が終わってからできます。変更・追加は、収集日の3日前（土日を除く）までに受付センターへ電話します。申し込みのときは、住所・氏名・電話番号・品目・大きさ・数のほか、戸建てか集合住宅か、収集車が通れるかを聞かれます。収集までの日数は公式ページに書かれていないので、引越しが決まったら早めに申し込みましょう。

料金は目安です。2026年10月30日に東大阪市 大型ごみの出し方とごみ分別検索（布団）で確認。ソファ・たんす・ベッドなども、品目ではなく3辺の合計で400円か800円になります。

  • 「大型ごみ処理券」（シール）を、必要な枚数だけ市内の取扱店で買います。ファミリーマート・ミニストップ・ローソン・セブン-イレブン（一部の店を除く）と、市役所本庁舎1階のヤマザキショップ東大阪市役所店で買えます。郵便局では令和5年4月から扱っていません。
  • 再発行・払い戻しはできません。近くの市町村の処理券とまちがえないようにしましょう。
  • 処理券（シール）の買い方

出し方

  • 処理券に「収集日」と「受付番号」を書き、大型ごみ1点ごとに貼ります。一度貼るとはがせません。
  • 収集日の朝9時までに、自宅前か申し込みのときに決めた場所に出します。立ち会いは要りません。
  • 9時までに出ていないと収集されず、もう一度申し込みが必要です。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）、家庭用パソコン、消火器、バイク
  • LPガスボンベ・シンナー・塗料・灯油などの危険な物、ボタン電池
  • 土・砂・ブロック・建築廃材、ピアノ・金庫・タイヤ・バッテリー、浴槽・流し台・便器、太陽光パネルなど（市で収集・処理できないごみ）

家電4品目は、市では収集しません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（事前の連絡は要りません）。市の近くの指定引取場所は、日本通運 大阪鶴見指定引取場所（大阪市鶴見区焼野3丁目2番24号）と、日本通運 八尾指定引取場所（八尾市神武町2丁目24番）です（市の家電リサイクルのページ・指定引取場所の検索・料金の目安）。

急ぐときは東大阪都市清掃施設組合へ持ち込む

  • 持ち込み先：東大阪都市清掃施設組合（東大阪市水走四丁目6番25号）。大型ごみで出せる物も持ち込めます。品目によっては、持ち込むほうが安いこともあります（例：プラスチックの衣装ケース）。
  • 予約：必要です。予約専用ダイヤル 072-975-5341（平日 9:00〜16:00）で、持ち込む日の2週間前から2日前まで（土日祝を除く）。当日・前日の予約はできません。
  • 持ち込める時間：月〜金曜 12:45〜15:30。祝日は 9:30〜11:30 と 12:45〜15:30 も受け付けます。
  • 料金の目安：10kgにつき90円（現金のみ）。処理券は使いません。
  • 持ち物：予約受付番号、運転免許証・健康保険証などの公的な身分証明書（計量所で見せます）、車検証、現金。求められたら公共料金の領収書など。
  • 決まり：最大積載量3トン以下・全長6.3m以内の車で、2人以上で乗っていきます。粗大ごみ・電気製品・金属のついた物と、それ以外の物は分けて積みます。家電4品目・パソコン・危険物・タイヤやピアノ・建築廃材は持ち込めません。
  • 引越しのごみも持ち込めますが、3月ごろは大変混み合います。持ち込めるかどうかは、市ではなく予約専用ダイヤルで確かめます。

東大阪市に引っ越してきた人へ

東大阪市の公式ページでは、引越しや転入について次のように案内しています（2026年10月30日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引っ越しにともなうごみは、予約すれば東大阪都市清掃施設組合（水走）へ持ち込める（3月ごろの引越しシーズンは大変混み合う）。
  • 持ち込みのときは、計量所で運転免許証や健康保険証などの公的な身分証明書を見せる。求められた場合は公共料金の領収書なども必要。
  • インターネット申し込みは、前回電話で申し込んだあと住所・氏名が変わっていない人だけ。転居した人は電話で申し込む。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。東大阪市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 受付に電話して、早い収集日がないか聞く（初めての人はインターネットで申し込めません）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）
