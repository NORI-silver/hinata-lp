高松市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、高松市の公式ページをもとにまとめました。

2026年10月31日に高松市の公式ページで確認・料金や日数は目安です

高松市では、粗大ごみは「臨時・粗大ごみ」と呼ばれ、ごみステーションには出せません。申し込みから収集まで7〜10日ほどかかり、手数料は510円・1,020円・1,530円・2,040円の段階です。引越しが決まったら早めに申し込みましょう（高松市の公式ページより）。

高松市のポイント
  • 対象の目安：縦・横・高さのどれかが1m×50cm×50cmを超える大きな物、引越しなどで出る多量のごみ
  • 料金：品目ごとに510円〜2,040円など（「臨時・粗大ごみ処理シール」は510円の1種類）
  • 申し込み：高松市粗大ごみ受付センター（電話）、インターネット（1回3点まで・条件あり）
  • 収集まで：7〜10日ほど。収集日の朝8時までに出す。立ち会いは要らない
  • 急ぐとき：南部・西部クリーンセンターへ持ち込める（予約不要の施設あり・重さで料金）

申し込み方法

  • 電話：高松市粗大ごみ受付センター 087-834-0366（月〜金曜 9:00〜16:00、土・日・祝日は休み）。間違い電話が多いので、番号をよく確かめてかけてください。月曜と祝日の翌日の午前中は混み合います。
  • インターネット：高松市 臨時・粗大ごみインターネット受付。1回3点まで（それより多いときは電話で相談）。前回の申し込みの収集が終わるまで、次のネット申し込みはできません。収集日は申込日の7日後から30日後の間で選びます。対象はインターネット受付用の品目リスト（PDF）にある品目だけです。

引越しで市外へ転出する人と、品目リストにない物は、電話で申し込みます。受付のときに住所・名前・連絡先・品目と数・収集車が玄関前まで入れるかを聞かれ、受付番号・収集日・収集場所・手数料を教えてもらえます。内容の変更は、収集日の2営業日前までに受付センターへ電話します（インターネット受付の案内）。

料金は目安です。2026年10月30日に高松市 臨時・粗大ごみの出し方の「主な品物の収集手数料」で確認。「1m×1m」は幅・高さ・奥行きのうち2つ以上で判断します。大きさや重さで表と違うことがあるので、申し込みのときに確かめてください。

  • 手数料は「臨時・粗大ごみ処理シール」（510円の1種類）で払います。1,020円なら2枚のように、案内された金額分の枚数を買います。市内のスーパー・コンビニなどで買えます（一部の店では扱っていません）。
  • 払い戻し・再発行はできません。シールの領収書（半券）は収集が終わるまで取っておきます。シールは施設への持ち込みには使えません。

処理券（シール）の買い方

出し方

  • 収集日の朝8時までに、申し込みで決めた場所（収集車が横付けできる所）に出します。立ち会いは要りません。
  • シールに受付番号を書き、手数料分のシールをすべて見やすい所に貼ります。一度貼るとはがせません。シールが足りない・貼っていないと収集されません。
  • 1回に出せる量に決まりがある品目があります（畳は8枚まで、障子・ふすまは10枚まで、自動車用タイヤは4本までなど）。
  • まだ使える物は、市と連携する「ジモティースポット高松うみまち商店街店」でリユースする方法もあります。

出せない物と家電4品目

  • テレビ、エアコン、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • 請負工事で出た物（サッシ・ドア・畳・流し台・浴槽・物置・温水器など）、フロンガス入りの冷風機・温風機
  • パソコン（パソコンの出し方）

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。市内の指定引取場所は市の家電リサイクルのページに載っています。なお市は、リサイクル券を用意したうえで受付センターに申し込めば、1品2,040円（処理シール）で立ち会いのもと収集するとしています。

急ぐときはクリーンセンターへ持ち込む

  • 南部クリーンセンター（塩江町安原下第3号2084番地1、087-890-2190）：破砕・粗大ごみは月〜金曜 8:30〜16:00（祝日も受付、土・日・年末年始は休み）。電話予約などは要りません。フロンガスを使う家電は持ち込めません。
  • 西部クリーンセンター（川部町930-1、087-885-2727）：燃やせるごみは平日 8:30〜16:30・土曜 8:30〜12:00、破砕ごみ（燃えない粗大ごみ）は土曜 8:30〜12:00だけ（日・祝日・年末年始は休み）。
  • 料金の目安：どちらも100kgまで一律1,700円、100kgを超えると20kgごとに340円を足します。車ごと量って、現金で払います。処理シールは使えません。
  • 手続き：南部では「一般廃棄物搬入申込書」に住所・名前・電話番号・ごみの種類を書きます。運転免許証や車検証を見せるよう言われることがあります。西部では住所と名前を聞かれます。
  • 持ち込めない物：家電4品目、高松市外のごみ・他人のごみ、危険物、分別していないごみなど。2トンを超える車・長さ5.5m以上の車（南部）では入れません。

高松市に引っ越してきた人へ

高松市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しなどで出る多量のごみは臨時・粗大ごみとして扱われ、ごみステーションには出せません。申し込みから収集まで7〜10日ほどかかるので、市は引越し前の早めの申し込みを案内しています。
  • 引越しで市外へ転出する人は、インターネットではなく粗大ごみ受付センターへの電話で申し込みます。
  • クリーンセンターへの持ち込みでは、住所と名前を確かめられます。南部クリーンセンターでは搬入申込書を書き、運転免許証や車検証を見せるよう求められることがあります。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。高松市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 受付に電話して、早い収集日がないか聞く（市外へ引っ越す人は電話で申し込みます）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

まだ使える家具や家電は、処分代がかからず値段がつくこともあるので、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらい、値段がつかなければ断って高松市の粗大ごみに切り替えます（どのお店とも提携していません）。
