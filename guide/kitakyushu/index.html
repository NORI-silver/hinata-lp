北九州市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、北九州市の公式ページをもとにまとめました。

2026年10月30日に北九州市の公式ページで確認・料金や日数は目安です

北九州市の粗大ごみは、市の指定袋（45リットル）に入らない大きさの物などが対象です。手数料は1個300円〜1,000円の4段階で、収集は地区ごとに月1回。引越しでたくさん出るときは、重さで払う「引越ごみ」の収集もあります（北九州市の公式ページより）。

北九州市のポイント
  • 対象：粗大ごみと決められた物と、指定袋（45リットル）に入らない物
  • 料金：300円・500円・700円・1,000円の4段階
  • 申し込み：インターネット（24時間・収集日の3日前まで）、電話（収集日の前日まで）
  • 収集：地区ごとに月1回。朝8時30分までに出す
  • 急ぐとき：焼却工場へ自分で持ち込める（10kgごとに150円）

申し込み方法

  • インターネット（24時間365日）：北九州市 粗大ごみ受付センター。収集日の3日前まで（日曜・年末年始を除く）。
  • 電話：粗大ごみ受付センター 093-513-3005（月〜土 9:00〜17:00、祝日も受付。12月29日〜1月3日は休み）。収集日の前日まで（日曜・年末年始を除く）。
  • ファクス（聴覚障害のある人）：093-531-5390

電話は朝9時〜10時と月曜の午前が混みます。収集日は地区ごとに決まっていて、資源とごみの収集日で確かめられます。

500円木製の机、ゴルフセット、ドア

2026年10月30日に北九州市 粗大ごみ・引越ごみで確認。料金は目安です。

  • 「粗大ごみ処理手数料納付券」（300円・500円・700円・1,000円）を、申し込んだあとに市内の指定袋取扱店（スーパー、コンビニなど）で買います。払い戻しはできません。
  • ネットで申し込んだ人は、PayPayや主要なクレジットカードでも払えます。払ったあとの返金・金額の変更はできず、領収証も出ません。

出し方

  • 納付券を貼り、収集日の朝8時30分までに、家の前か指示された場所に出します。
  • キャッシュレスで払った人は、一辺20cmくらいの紙に受付番号・収集日・品目ごとの金額を油性ペンで書いて、しっかり貼ります。はがれると収集されないことがあります。
  • 高齢の人や障害のある人などだけの世帯は、1個500円で家の中から運び出す「持ち出しサービス」を電話で頼めます（引越ごみには使えません）。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • バイク、消火器、ガスボンベ、タイヤ、バッテリー、ピアノ、大型の金庫など
  • 増改築・解体で出たごみ、事業所から出たごみ

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ運びます（指定引取場所の検索・料金の目安）。市が収集しない物の相談先は市の公式ページにまとまっています。

急ぐときは焼却工場へ持ち込む・引越ごみを頼む

  • 自己搬入：新門司工場（門司区）、日明工場（小倉北区）、皇后崎工場（八幡西区）へ自分で運べます。料金は10kgごとに150円（2027年9月1日から10kgごとに230円になる予定）。予約はいらず、「廃棄物搬入申込書」を書いて行きます。運転免許証など写真つきの本人確認書類が必要です。
  • 受付時間は工場ごとに違い、日曜は短くなります。不燃粗大ごみは日明工場の不燃粗大仮置場（日曜は受け入れなし）です（受付時間の一覧）。
  • 引越ごみ：一度にたくさん出るときは、収集希望日の1週間前までに 093-513-3005 へ。認定員が家に来てごみの量を確かめ、100kgごとに2,300円をその場で払います。収集は月〜金曜から選べます。
  • リユース：市はジモティーと連携していて、まだ使える家具・家電を手数料なしで譲れます。

北九州市に引っ越してきた人へ

前の家から持ってきた家具などを北九州市で粗大ごみに出すときの決まりは、北九州市の公式ページには特に書かれていませんでした（2026年10月30日確認）。北九州市の家庭のごみとして申し込むので、申し込むときに「引越しで持ってきた物」と伝えて確かめると安心です。

  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。北九州市の分け方に従って出します。
  • 引越などで一度に大量に出るごみは「引越ごみ」として、収集希望日の1週間前までに電話（093-513-3005）で申し込み、認定員が量を確かめて100kgごとに2,300円を徴収します。
  • 焼却工場への自己搬入では、運転免許証など写真つきの本人確認書類の提示が必要です。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。家庭のごみを運べるのは市区と市区の許可業者だけです（ぼったくりの実例と見分け方）。

北九州市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、北九州市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
