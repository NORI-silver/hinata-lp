奈良市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、奈良市の公式ページをもとにまとめました。

2026年10月30日に奈良市の公式ページで確認・料金や日数は目安です

奈良市では、粗大ごみを大型ごみと呼び、45リットルの袋に入らない物が対象です。申し込みは1回4点までで、令和8年6月から令和9年3月までは2か月に1回・年2回までに限られています。引越しで出るごみは市では収集しないので、早めに準備しましょう（奈良市の公式ページより）。

奈良市のポイント
  • 対象の目安：単体で45リットルの袋に入らない物
  • 申し込み：大型ごみ申込専用電話（月〜金曜、祝日も受付）か、インターネット（2年以内に電話で申し込んだ人）
  • 回数と点数：1回4点まで。2か月に1回・年2回まで（令和8年6月1日〜令和9年3月31日）
  • 出し方：収集日の朝7時30分までに「奈良市申込品」と名字を書いた紙を貼って出す
  • 引越しのごみ：市では収集しない。環境清美工場へ予約して持ち込む（家庭ごみは100kgまで無料）か許可業者へ

申し込み方法

  • インターネット（24時間）：奈良市 大型ごみ収集のインターネット受付。ただし、2年以内に電話で申し込んだことがある人だけ使えます。前に電話で伝えた氏名（フリガナ）・町名・電話番号が完全に一致している必要があります。キャンセルは電話だけです。
  • 電話：奈良市 大型ごみ申込専用電話 0742-71-9011（月〜金曜 8:00〜15:00、祝日も受付）。自動音声のあとに職員につながります。一部の地域は受付の電話番号が違うので、市の大型ごみのページで確認してください。
  • ネット受付の相談：ごみインターネット受付相談窓口 0742-71-9202（月〜金曜 8:00〜16:00、祝日も受付）

申し込むのは、ごみが出る家に住む人で、世帯主の名前で申し込みます。代理の申し込みはできません。収集日は住所で決まり、申し込んだ当日の収集はありません。追加・変更は収集日の2日前（土日を除く）まで、12月は追加・変更ができません。空き家などの片付けの収集は受け付けていません。

料金の目安と払い方

市の大型ごみのページには、収集の手数料や処理券についての記載が見当たりません（2026年10月30日確認）。品目ごとの料金表もないため、ここでは表を載せていません。申し込みのときに確かめてください。ほかの市で使う処理券（シール）の買い方もまとめています。

出し方

  • 収集日の朝7時30分までに、ごみ収集車が安全に通れる場所に出します。
  • 「奈良市申込品」と出す人の名字を書いた紙（B5以上）を、ガムテープで貼ります。大きさの確認が要る品目は「大・中・小」も書きます（大：一辺1.8m以上2.5m未満、中：1m以上1.8m未満、小：1m未満）。
  • 布団は1mくらいにたたんで縛ります。よしず・籐の敷物は半分に切って丸めて縛ります。
  • 別の車で集める品目があるので、残っていてもその日は出したままにします。
  • 落ち葉・雑草・せん定枝は大型ごみでは申し込めません。

出せない物と家電4品目

  • テレビ、エアコン、冷蔵庫・冷凍庫、洗濯機、衣類乾燥機（家電リサイクル法の対象）、パソコン
  • ガスボンベ・灯油・オイル、消火器・バッテリー・農薬・薬品類、ピアノ・農機具・コンクリート片など
  • 引越しで出るごみ

家電4品目は、市では収集しません。環境清美工場にも持ち込めません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。

引越しのごみは環境清美工場へ持ち込む

引越しで出るごみは、市では収集しません。環境清美工場へ自分で持ち込む（予約が必要）か、市の許可業者に有料で頼みます。

  • 場所：環境清美センター（環境清美工場、奈良市左京五丁目2番地、ごみの内容の相談 0742-71-3000）
  • 予約：必要です。前日まで（土日を除く）に、持込ごみ予約電話 0742-71-9011（月〜金曜 8:00〜15:00、祝日も受付）か、持込ごみのインターネット受付（24時間）で予約します。工場へ直接行っても、工場に電話しても予約できません。予約できるのは申し込んだ月と翌月の分です。
  • 持ち込める時間：月〜金曜（祝日を含む）の10:00〜12:00と13:00〜15:00。
  • 料金の目安：家庭のごみは100kgまで無料、超えた分は10kgにつき100円。
  • 回数：家庭のごみの持ち込みは年6回まで（令和8年6月から）。
  • 持ち物と決まり：本人確認の免許証などと、重さの確認のための車検証。持ち込めるのは、そのごみが出た家に住む人だけです。袋は透明か半透明。トラックは2トン（ロング不可）まで。
  • 令和8年6月1日〜11月30日の制限：焼却炉が止まっているため、燃やせるごみと一部の大型ごみ（ごみ事典で工場持込場所3番の物）は持ち込めません。燃やせないごみ・不燃性の大型ごみ・自転車などは持ち込めます。
  • 持ち込めない物：家電4品目、パソコン、ピアノ・バイク・タイヤなどの処理困難物、流し台・便器・瓦などの建築廃材、土・砂・石、市外のごみ。

くわしくは市の持ち込み方法のページで確認してください。持ち込みの準備と持ち物

奈良市に引っ越してきた人へ

奈良市の公式ページでは、引越しや転入について次のように案内しています（2026年10月30日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引っ越しにともなうごみは市では収集しない。環境清美工場へ予約して持ち込むか、市の許可業者に有料で頼む。
  • 大型ごみのインターネット受付は、2年以内に電話で申し込んだことがある人だけ使える。初めての人は電話で申し込む。
  • 環境清美工場への持ち込みは、そのごみが出た家に住む人だけ。本人確認の免許証などと車検証を見せる。引越しのごみも予約が必要。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。奈良市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 引越しのごみは市では収集しないので、持ち込みを予約する（前日まで、土日を除く）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

奈良市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、奈良市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
