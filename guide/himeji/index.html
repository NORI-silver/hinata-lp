姫路市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、姫路市の公式ページをもとにまとめました。

2026年10月31日に姫路市の公式ページで確認・料金や日数は目安です

姫路市（旧姫路市域）では、指定袋に入らない物を、種類ごとに分けて地区の粗大ごみステーションへ出します。収集は月2回で、1点は長さ2m以下・50kg未満が目安です。引越しで出るごみはステーションに出せないので、早めに持ち込みの準備をしましょう（姫路市の公式ページより）。

姫路市のポイント
  • 対象の目安：指定袋に入らない物。1点は長さ2m以下・50kg未満（旧姫路市域）
  • 出し方：木製品類・金属複合製品類・プラスチック複合製品類・ふとん・ジュータン類・陶磁器類に分け、粗大ごみステーションへ（月2回）
  • 申し込み：市の案内には予約の受付先がない。収集日は地区別クリーンカレンダーで確認
  • 引越しのごみ・50kg以上の物：ステーションには出せない。エコパークあぼしへ持ち込むか許可業者へ
  • 持ち込み：エコパークあぼし（10kgあたり130円、引越しごみは事前に連絡）

申し込み方法

  • 申し込み：旧姫路市域では、地区の粗大ごみステーションへ決まった日に出す方式です。市の案内に、粗大ごみの予約の受付先は載っていません。収集日は一般家庭用クリーンカレンダーで、住所から調べます。
  • 電話：姫路市 リサイクル課 079-221-2404（出し方や収集日の問い合わせ）

使うステーションは地域で決まっています。わからないときは、ご近所の方か自治会に、マンションなどは管理会社に聞きます。夢前町・香寺町・安富町・家島町の地域は出し方が違うので、市の大型ごみ（夢前・香寺・安富）・大型ごみ等（家島）のページで確認してください。

料金の目安と払い方

旧姫路市域のステーション収集について、市の案内に手数料や処理券の記載は見当たりません（2026年10月30日確認）。品目ごとの料金表もないため、ここでは表を載せていません。気になるときはリサイクル課（079-221-2404）で確かめてください。ほかの市で使う処理券（シール）の買い方もまとめています。

出し方

  • 収集日の朝8時までに、地区の粗大ごみステーションへ出します（夜間収集の地区は夜10時まで）。
  • 木製品類（机・イス・ベッド・タンスなど）：できるだけこわして束ねます。竹・笹・よしずは80cm以下に切ります。
  • 金属複合製品類（自転車・スプリング入りマットレス・電子レンジ・ストーブなど）：できるだけばらします。ストーブは油と電池を抜きます。
  • プラスチック複合製品類（ホース・照明器具・大きな発泡スチロールなど）：蛍光管・電球は「蛍光管」の日に分けて出します。
  • ふとん・ジュータン類（ふとん・じゅうたん・スプリングのないマットレス・毛布など）：中身の見える袋に入れるか、丈夫なひもで結びます。
  • 1点ずつ50kg未満でも、一度に出す量の合計は50kgまでです。

出せない物と家電4品目

  • テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機、エアコン（室外機を含む）（家電リサイクル法の対象）
  • 家庭のパソコン（メーカーの回収などへ）
  • ガスボンベ・消火器・タイヤ・バッテリーなどの危険な物（危険なごみ等の処理方法）
  • 引越しで出るごみ、50kg以上の重い物

家電4品目は、市では収集も処理もしません。粗大ごみステーションにも、市の施設にも出せません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます。買ったお店がないときは、市が案内する兵庫県電機商業組合の登録店にも頼めます。市内の指定引取場所は市のページに2か所載っています（市の特定家電品のページ・指定引取場所の検索・料金の目安）。

引越しのごみはエコパークあぼしへ持ち込む

引越しで出るごみは、市では収集しません。近くの可燃ごみ・粗大ごみステーションにも出せません。分別して自分で処理施設へ運ぶか、市の許可業者に有料で頼みます（引越しごみの処理方法）。

  • 持ち込み先（旧姫路市域）：エコパークあぼし（姫路市網干区網干浜4番地1、計量受付 079-272-5540、事務所 079-272-5551）。家具などはそのまま持ち込めます。
  • 事前の連絡：引越しごみ、50kg以上の重い物、たくさんの木くず・剪定枝は、前もって事務所へ連絡します。
  • 受付：月〜土曜 8:00〜17:00（日曜・12月31日〜1月3日は休み）。混雑を避けるため16時30分までの受付をお願いしています。ゴールデンウィークと年末は混みます。
  • 料金の目安：10kgあたり130円（車1台ごとに計算）。
  • 決まり：持ち込めるのは本人か市の許可業者だけです。分別せずに混ぜて積むと、持ち帰りになることがあります。スプレー缶などは分けて受付で伝えます。荷台はシートやネットでおおいます。
  • 市川美化センターは袋に入った可燃ごみだけで、粗大ごみは持ち込めません。

夢前町・香寺町・安富町の地域はくれさかクリーンセンター（埋立ごみが中心で、前もって地域事務所での手続きが必要）、家島町の地域は家島美化センター（処分券が必要）へ持ち込みます（市の持ち込みのページ）。持ち込みの準備と持ち物

姫路市に引っ越してきた人へ

姫路市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しで出るごみと50kg以上の重い物は、市では収集しない。近くの可燃ごみ・粗大ごみステーションにも出せない。
  • 引越しごみは分別して処理施設へ自分で運ぶ（有料）か、市の許可業者に頼む。
  • エコパークあぼしへ引越しごみを持ち込むときは、前もって事務所へ連絡する。持ち込めるのは本人か市の許可業者だけ。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。姫路市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 引越しで出るごみはステーションに出せないので、市に連絡してエコパークあぼしへ持ち込む
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

姫路市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、姫路市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
