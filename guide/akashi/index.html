明石市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、明石市の公式ページをもとにまとめました。

2026年10月31日に明石市の公式ページで確認・料金や日数は目安です

明石市では、45リットルの袋に入らない物か、約5kgを超える物が粗大ごみです。事前の申し込みと手数料が必要で、引越しシーズンなどの混む時期は、いちばん早い収集日でも約2週間先になることがあります。引越しが決まったら早めに申し込みましょう（明石市の公式ページより）。

明石市のポイント
  • 対象の目安：標準サイズのポリ袋（45リットル）に入らない物、または約5kgを超える物
  • 料金：品目ごとに300円〜2,100円ほど（処理券は1枚300円）
  • 申し込み：インターネット、または明石市粗大ごみ受付センターへ電話。1回5点まで
  • 収集まで：申し込んだ当日・翌日は不可。混む時期は約2週間先。収集日の朝8時までに出す
  • 急ぐとき：明石クリーンセンターへ予約して持ち込める（家庭の可燃ごみは10kgあたり50円）

申し込み方法

  • インターネット：明石市 粗大ごみ収集インターネット受付。休日明けは電話が混むので、市もネットの利用をすすめています。
  • 電話：明石市粗大ごみ受付センター 078-937-0937（月〜金曜 9:00〜17:00、祝日も受付）

1回の申し込みで出せるのは5点までです。申し込んだ当日と翌日の収集はできません。収集日は月〜土曜（祝日を含む）です。電話のときは、品目・処理券の枚数・収集日・出す場所が決まるので、メモを用意し、家具は幅・奥行き・高さを測っておきます。キャンセルは収集日の当日でも必ず電話で連絡します。

出し方

  • 収集日の朝8時までに、申し込みのときに決めた場所に出します。前の日から出さないでください。立ち会いは要りません。
  • 収集は朝8時からおおむね午後3時までで、時間は選べません。
  • 職員は家の中に入りません。倒れないように置き、狭い路地では広い道路まで出すように言われることがあります。
  • 申し込んでいない物や、処理券の金額が足りない物は収集されません。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • 家庭のパソコン（メーカーなどの回収へ）
  • 市で出せない物（ごみに出せないもの）
  • 引越しなどで一度に多量に出たごみ（市は自分で処理するよう求めています。クリーンセンターへ持ち込むか許可業者へ）

家電4品目は、ごみとして出せません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます。買ったお店がわからないときは、市の協力店にも頼めます（市の家電4品目のページ・指定引取場所の検索・料金の目安）。

急ぐときは明石クリーンセンターへ持ち込む

  • 予約：必要です。明石市粗大ごみ受付センター（078-937-0937、月〜金曜 9:00〜17:00、祝日も受付）か、インターネットで予約します。当日の予約はできません。予約のときに、日時・ごみの種類・車を伝えます。
  • 持ち込める時間：月〜土曜（祝日を含む）の9:00〜11:30と13:00〜15:30。土曜は混むので、平日をすすめられることがあります。
  • 料金の目安（家庭のごみ・10kgあたり）：可燃50円、不燃（破砕）60円、埋立60円。可燃と不燃などを混ぜて積むことはできません。
  • 持ち物と決まり：持ち込む人の身分証明書と手数料。持ち込めるのは、ごみを出した本人か市の許可業者だけです。車は4トン車以下で、分別して自分で降ろします。
  • 持ち込めない物：家電4品目、タイヤ、消火器、LPガスボンベ、薬品類、ピアノなど。市外のごみも持ち込めません。たくさん出るときは、施設から指示があることがあります。

まだ使える物は、市が案内する「ジモティースポット明石魚住店」に予約なしで無料で持ち込めます（再販できる物のみ）。市の持ち込みのページ・持ち込みの準備と持ち物

明石市に引っ越してきた人へ

明石市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引っ越し前に収集が終わるよう、早めに申し込むよう案内している。
  • 引越しシーズン・夏・年末などの混む時期は、いちばん早い収集日でも約2週間先になることがある。
  • 明石クリーンセンターへの持ち込みは前もって予約が必要で、当日の予約はできない。持ち込む人の身分証明書が必要。
  • 引越しなどで一度に多量に出たごみは、市は自己処理（クリーンセンターへの持ち込みか許可業者）を求めている。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。明石市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

明石市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、処分代がかからず値段がつくこともあるので、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらい、値段がつかなければ断って明石市の粗大ごみに切り替えます（どのお店とも提携していません）。

セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどの買取チェーンが出張買取をしています。
