文京区の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、文京区の公式ページをもとにまとめました。

2026年10月30日に文京区の公式ページで確認・料金や日数は目安です

文京区の粗大ごみは、家庭から出た家具・電化製品などで一辺がおおむね30cm以上の物です。年末年始や引越しの多い季節は、申し込みから収集まで2〜3週間以上かかることがあります。早めに申し込みましょう（文京区の公式ページより）。

文京区のポイント
  • 対象：一辺がおおむね30cm以上の家具・電化製品など
  • 申し込み：インターネット・チャットボット（24時間）、電話（月〜土 8:00〜19:00）
  • 料金：品目ごとに400円〜3,200円が目安。処理券A（200円）・B（300円）で払う
  • 収集まで：繁忙期は2〜3週間以上かかることがある。朝8時までに出す
  • リユース：ジモティーと連携した引き取りサービスがあり、最短で当日引き取りも

申し込み方法

  • インターネット（24時間）：文京区 粗大ごみ受付センター。料金の確認もここでできます。
  • チャットボット（24時間）：区の粗大ごみのページから使えます。
  • 電話：文京区粗大ごみ受付センター 03-5296-7000（月〜土 8:00〜19:00）。電話番号の入力間違いに注意してください。

インターネット・チャットボット・電話とも、12月28日〜1月4日は休みです。収集曜日は地域によって違い、申し込みのときに案内されます。

  • 「有料粗大ごみ処理券」A券（200円）・B券（300円）を、品目ごとの料金分組み合わせて買います（例：両袖机3,200円はA券1枚・B券10枚）。
  • 区内の「有料粗大ごみ処理券取扱所」の標識があるお店で買えます（取扱所のページ）。2021年10月にデザインが変わりましたが、新旧どちらの券も使えます。

出し方

  • 処理券に収集予定日と、氏名（集合住宅は部屋番号も）または受付番号を書いて、品目ごとに料金分を貼ります。
  • 収集日の朝8時までに、自宅の前に出します。集合住宅は建物1階の出入り口スペースなど、収集できる場所へ。

出せない物と家電4品目

  • テレビ、エアコン、冷蔵庫（冷凍庫）、洗濯機・衣類乾燥機
  • パソコン
  • バッテリー、金庫、オートバイ、自動車など
  • 事業者が出す物（許可を受けた専門業者に頼みます）

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ運びます（指定引取場所の検索・料金の目安）。区の案内は文京区 家電4品目のページへ。

持ち込み

文京区の公式ページには、家庭の粗大ごみを自分で持ち込む方法の記載が見当たりません。急ぐときや大量に出るときは、文京清掃事務所（03-3813-6661）に問い合わせてください。まだ使える物は、区が案内しているジモティーと連携したリユースなら、最短で当日に引き取ってもらえることがあります。

文京区に引っ越してきた人へ

前の家から持ってきた家具などを文京区で粗大ごみに出すときの決まりは、文京区の公式ページには特に書かれていませんでした（2026年10月30日確認）。文京区の家庭のごみとして申し込むので、申し込むときに「引越しで持ってきた物」と伝えて確かめると安心です。

  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。文京区の分け方に従って出します。
  • 年末年始や引越しの多い季節は、申し込みから収集日まで2、3週間以上かかる場合があります。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。家庭のごみを運べるのは市区と市区の許可業者だけです（ぼったくりの実例と見分け方）。

文京区の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、文京区の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
