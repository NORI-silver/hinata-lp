八尾市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、八尾市の公式ページをもとにまとめました。

2026年10月31日に八尾市の公式ページで確認・料金や日数は目安です

八尾市の粗大ごみは事前の申し込みが必要で、手数料は1点400円、3辺（高さ・幅・奥行き）の合計が3mを超える物は1点800円です。1回に8点まで出せます。申し込む前に3辺の長さを測っておきましょう（八尾市の公式ページより）。

八尾市のポイント
  • 対象：指定袋に入らない大きなごみ（家具類、リサイクル家電を除く電化製品など）
  • 料金：1点400円、3辺の合計が3mを超える物は1点800円（一部例外あり）
  • 申し込み：八尾市粗大ごみ受付センター（電話・通話料無料）かインターネット。1世帯1回8点まで
  • 出し方：手数料券に収集日と受付番号を書いて貼り、収集日の朝8時30分までに出す
  • 急ぐとき：予約して八尾市立リサイクルセンターへ持ち込める（10kgにつき200円・現金のみ）

申し込み方法

  • インターネット：八尾市 粗大ごみインターネット受付。メールアドレスを使って申し込みます。収集車の入口（70cm×100cm）に入らない物、厚さ5cm以上の木材など、男性2人で持ち上げにくい重い物、品目一覧にない物はネットでは申し込めないので、電話で申し込みます。
  • 電話：八尾市粗大ごみ受付センター 0800-222-9966（通話料無料）、携帯電話・一部のIP電話からは 072-923-9966（月〜金曜 9:00〜17:00、祝日も受付。土日・年末年始は休み）
  • ファクス：072-923-0030。申込書は市のページからダウンロードできます。

1世帯1回につき8点までです。次に申し込めるのは、収集から1か月たってからです。追加・品目の変更は収集日の4日前まで、取り消しは前日まで（どちらも土日・年末年始を除く）に受付センターへ連絡します。収集日の4日前からは、インターネットでの追加・変更・取り消しはできません。番号の間違い電話が多いので、かける前に番号を確かめてください。

料金の目安と払い方

区分料金
粗大ごみ（指定袋に入らない大きな物）1点400円
粗大ごみ（3辺の合計が3mを超える物）1点800円
臨時ごみ（引越しなどで一時的にたくさん出るとき）2トン車1台20,000円
リサイクルセンターへ持ち込み（粗大ごみ・複雑ごみ・資源物）10kgにつき200円

料金は目安です。2026年10月31日に八尾市 粗大ごみの出し方・臨時ごみの出し方で確認。一部に例外の品目があるので、品目ごとの金額は申し込みのときに受付センターで確かめてください。

  • 「八尾市粗大ごみ手数料券」を、案内された金額の分だけ取扱店で買います。取扱店は市の粗大ごみのページの一覧で確かめます。郵便局での販売は終わっています。
  • 臨時ごみは、収集のあとに届く納付書で、決められた期限までに指定の金融機関で払います。

処理券（シール）の買い方

出し方

  • 手数料券に収集日と受付番号を書き、品物1点ごとに目立つところへ貼ります。券がない・足りないときは収集されません。
  • 収集日の朝8時30分までに、指定された場所に出します。収集は8時30分ごろから15時30分ごろまで順番にまわり、時間は選べません。
  • 石油ストーブなどは、必ず石油を抜いてから出します（収集車の火事の原因になります）。
  • 引越しで住所・連絡先・出す場所が変わるときは、インターネットでは変更できないので受付センターに電話します。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • スプリング入りマットレス、オイルヒーター、ピアノ、仏壇・神棚、手提げ以外の金庫、消火器、バッテリー、タイヤ、ガスボンベ、オートバイ・ミニバイク、レンガ・ブロックなど
  • 産業廃棄物、建築廃材、廃油・塗料、事業活動から出たごみ

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。買ったお店が分からないときなどは、粗大ごみ受付センターに申し込むと、リサイクル料金のほかに手数料2,500円で市が収集する方法もあります（市のリサイクル家電のページ）。

急ぐときはリサイクルセンターへ持ち込む

  • 持ち込み先（粗大ごみ・複雑ごみ・資源物）：八尾市立リサイクルセンター（曙町2-11、072-992-2060）
  • 予約：必要です。市の電子申請システムで予約します（持ち込み予約のページ）。
  • 受付：月・火・木・金曜（水曜以外の祝日も受付）の9:00〜11:45と13:00〜16:00。
  • 料金の目安：10kgにつき200円。現金のみです。
  • 持ち物と決まり：運転免許証など本人を確かめる書類。出す本人か同じ世帯の人が運転する自家用車で持ち込みます。会社名や屋号の入った車、代理の人の持ち込みはできません。
  • 家電4品目、パソコン、スプリング入りマットレス、リフォームや解体で出たたたみ・ふすま・流し台などは持ち込めません。

引越しなどで一時的にたくさん出るときは、粗大ごみ受付センターに電話して「臨時ごみ」を頼めます（2トン車1台20,000円、当日は立ち会い）。家の中からは運び出しません。

八尾市に引っ越してきた人へ

八尾市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しで住所・連絡先・出す場所が変わるときは、インターネットでは変更できないので粗大ごみ受付センターに電話します。
  • 引越しなどで一時的にたくさん出るごみは、粗大ごみ受付センターに電話して臨時ごみ（2トン車1台20,000円）として頼めます。
  • リサイクルセンターへの持ち込みは、出す本人か同じ世帯の人が運転する自家用車だけで、運転免許証など本人を確かめる書類が要ります。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。八尾市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

八尾市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、八尾市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
