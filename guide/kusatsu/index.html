草津市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、草津市の公式ページをもとにまとめました。

2026年10月31日に草津市の公式ページで確認・料金や日数は目安です

草津市（滋賀県）では、縦・横・高さのどれかが50cmを超える物か、1個10kgを超える物が粗大ごみです。収集は地区ごとに月2回で、申し込みは収集日の7日前まで。手数料は品目ごとに800円か1,500円が中心なので、引越しが決まったら早めに申し込みましょう（草津市の公式ページより）。

草津市のポイント
  • 対象：縦・横・高さのどれかが50cmを超える物、または1個10kgを超える物
  • 料金：品目ごとに800円・1,500円など。粗大ごみ処理券を指定ごみ袋等取扱店で買って貼る
  • 申し込み：粗大ごみコールセンター（電話・平日）、草津市公式LINE（24時間）。収集日の7日前まで
  • 収集：地区ごとに月2回（第1・3または第2・4の決まった曜日）。収集日の朝8時までに屋外へ。立ち会い不要
  • 持ち込み：草津市クリーンセンターへ予約制。200kg未満は10kgあたり110円（現金のみ）

申し込み方法

  • インターネット（LINE・24時間）：草津市公式LINEアカウントを友だち追加し、「粗大ごみ収集予約」を選びます。2026年9月1日に始まりました。締め切りは電話と同じです。
  • 電話：草津市 粗大ごみコールセンター 077-561-2300（平日 8:30〜17:15、土日祝日・年末年始は休み）

収集日の7日前までに申し込みます。締め切りの日が土日祝日のときは、その前の平日が締め切りです。住所、氏名、電話番号、品目、個数を伝えます。寸法を測っておくと料金の確認がすみやかです。前日までなら取り消せますが、処理券は払い戻されず、次の申し込みで使います。1回に出せる点数は市のページに書かれていないので、申し込むときに確かめてください。

出し方

  • 収集は地区ごとに月2回、決まった曜日です（例：志津A・Bは第1・3月曜、草津A・Bは第2・4火曜）。自分の地区の曜日は市の粗大ごみのページで確かめてください。
  • 処理券に氏名（名字だけ・カタカナでも可）と収集日を書き、見やすいところに貼ります。
  • 収集日の朝8時までに、玄関先など前もって決めた屋外の場所に出します。家の中からは運び出しません。立ち会いは要らず、留守でも収集します。時間の指定はできません。
  • 申し込みと違う物、処理券がない・金額が足りない物は収集されません。
  • 状態のよい物は、修理してフリマアプリなどで売られることがあります。望まないときは処理券のチェック欄に印をつけます。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象。粗大ごみとは別の扱い）
  • パソコン（家庭用パソコンの出し方へ）
  • 会社やお店で使っていた物

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。なお草津市は、家電4品目の収集運搬を手数料を払って市に頼む方法も案内しています（市の処分方法（PDF））。

急ぐときは草津市クリーンセンターへ持ち込む

  • 場所：草津市クリーンセンター（草津市馬場町1200番地25）。草津市の家庭ごみだけ受け付けます（ほかの市町のごみは不可）。
  • 予約：必要です。予約がないと持ち込めません。LINE（「クリーンセンター持込予約」）とインターネットは24時間受付で持ち込む日の3営業日前まで、電話は予約コールセンター 077-516-4030（平日 8:30〜17:15）で2営業日前までです（持ち込み予約のページ）。
  • 搬入時間：月〜土曜（祝日を含む、年末年始を除く）の8:30〜11:30と13:00〜15:30。30分ごとの枠です。
  • 料金の目安：1回の量が200kg未満は10kgあたり110円、200kg以上は10kgあたり210円。現金のみです。指定袋に正しく分けた焼却ごみ・プラスチック製容器類・ペットボトル類は無料です。
  • 持ち物と決まり：本人確認書類、草津市に住んでいるとわかる書類（運転免許証・公共料金の通知など）、現金、予約の発行番号。持ち込めるのは原則ごみを出した本人で、荷下ろしも自分で行います。1日1世帯1回・車1台まで。車は自家用車か最大積載量2トン以下の平ボディ車です。
  • 家電4品目は持ち込めません。分別していないごみは持ち帰りになります。

草津市に引っ越してきた人へ

草津市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 草津市クリーンセンターへの持ち込みは予約制で、草津市の家庭ごみだけ受け付けます。本人確認書類と、草津市に住んでいるとわかる書類が必要です。
  • 持ち込めるのは原則ごみを出した本人で、1日1世帯1回・車1台までです。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。草津市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 受付に電話して、早い収集日がないか聞く
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

草津市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、処分代がかからず値段がつくこともあるので、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらい、値段がつかなければ断って草津市の粗大ごみに切り替えます（どのお店とも提携していません）。

セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどの買取チェーンが出張買取をしています。
