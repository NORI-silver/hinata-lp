新宿区の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、新宿区の公式ページをもとにまとめました。

2026年10月30日に新宿区の公式ページで確認・料金や日数は目安です

新宿区の粗大ごみは、一辺がおおむね30cmを超える家具・寝具・自転車などが対象です。手数料は品目ごとに400円〜3,200円（主な品目の例）で、新宿区専用の処理券を貼って出します。インターネットの取り消し・変更は収集日の3日前までなので、引越しの日が決まったら早めに申し込みましょう（新宿区の公式ページより）。

新宿区のポイント
  • 対象：一辺がおおむね30cmを超える家具・寝具・電気製品・自転車など
  • 申し込み：インターネット（24時間）、電話（月〜土 8:00〜19:00）
  • 支払い：新宿区専用の有料粗大ごみ処理券A（200円）・B（300円）の組み合わせ
  • 出す時間：収集日の当日の朝
  • 持ち込み：区の公式ページに記載が見当たらない（受付センターで確認）

申し込み方法

  • インターネット（24時間）：新宿区 粗大ごみ受付センター。取り消し・変更は収集日の3日前の23:59まで。
  • 電話：新宿区 粗大ごみ受付センター 03-5304-8080（月〜土 8:00〜19:00）

2026年10月30日に新宿区 粗大ごみの処理手数料一覧で確認。料金は目安です。

  • 処理券はA券（200円）・B券（300円）の2種類。コンビニなど「有料粗大ごみ処理券及び有料ごみ処理券取扱所」の標識があるお店、清掃事務所・清掃センター、各特別出張所、区役所7階のごみ減量リサイクル課で買えます（販売所の一覧）。
  • 一覧にない品目は受付センターに問い合わせます。

出し方

  • 収集日の当日の朝に、処理券を品目ごとに貼って、申し込みのときに決めた場所に出します。
  • 戸建ては玄関先や門の前、集合住宅は1階出口付近など。ふだんの資源・ごみの集積所とは場所が違うことがあります。
  • 解体しても粗大ごみとして出します。たんすなどの中に物を入れたままでは収集されません。
  • 65歳以上のひとり暮らしの人や障害のある人は、運び出し収集を使えます。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）、パソコン
  • 自動車、オートバイ、タイヤ、ピアノ、耐火金庫など（清掃事務所に聞くと専門業者を紹介してもらえます）
  • 事業者が出す粗大ごみ

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ運びます（指定引取場所の検索・料金の目安）。区の案内は家電4品目の出し方へ。

持ち込み

新宿区の公式ページには、家庭の粗大ごみを持ち込む方法の記載が見当たりませんでした。持ち込みたいときは、粗大ごみ受付センター（03-5304-8080）か新宿清掃事務所に問い合わせてください（区の粗大ごみのページ）。

新宿区に引っ越してきた人へ

前の家から持ってきた家具などを新宿区で粗大ごみに出すときの決まりは、新宿区の公式ページには特に書かれていませんでした（2026年10月30日確認）。新宿区の家庭のごみとして申し込むので、申し込むときに「引越しで持ってきた物」と伝えて確かめると安心です。

  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。新宿区の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。家庭のごみを運べるのは市区と市区の許可業者だけです（ぼったくりの実例と見分け方）。

新宿区の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、新宿区の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
