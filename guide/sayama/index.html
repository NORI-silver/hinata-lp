狭山市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、狭山市の公式ページをもとにまとめました。

2026年10月31日に狭山市の公式ページで確認・料金や日数は目安です

狭山市では、一辺が30cmを超える家具や電化製品などが粗大ごみです。予約収集は1点ごとの重さで200円〜1,800円、予約から収集まで約20日かかります。急ぐときは、予約なしで奥富環境センターに持ち込めます（狭山市の公式ページより）。

狭山市のポイント
  • 対象：一辺が30cmを超える家庭の家具・電化製品など（家電4品目を除く）
  • 申し込み：予約専用電話（月〜金曜 8:30〜15:30）か電子申請。1回5点まで
  • 料金の目安：1点ごとに重さで200円〜1,800円。収集のときに払う
  • 収集まで：予約から約20日。収集は月〜金曜
  • 引越しなどで一度にたくさん出るごみは集積所に出せない。持ち込むか許可業者に頼む
  • 持ち込み：奥富環境センターへ予約なしで。50kg未満は無料、50kg以上は10kgごとに90円

申し込み方法

  • インターネット（電子申請）：狭山市 粗大ごみ予約収集の電子申請。市の資料では利用者登録が必要とされています。問い合わせフォームのメールからは申し込めません。
  • 電話：奥富環境センター内の予約専用電話 04-2953-2832（月〜金曜 8:30〜15:30、祝日・振替休日・年末年始は休み）

1回の予約で5点までです。収集は月〜金曜（祝日・振替休日・年末年始を除く）で、午前か午後は選べますが、時間の指定はできません。予約から収集までは約20日かかります。希望の日に収集できないこともあるので、引越しが決まったら早めに予約しましょう。

料金の目安と払い方

料金は目安です。2026年10月31日に狭山市 粗大ごみの処分方法で確認。品目ごとの金額表はなく、1点ずつの重さで決まります。

  • 収集と料金の受け取りは同時に行います。支払いが済むまで、次の予約はできません。
  • 家にいないときの払い方は、市のよくある質問で確かめてください。
  • 市外へ引っ越すときは、収集に立ち会いが必要です。
  • 狭山市は処理券（シール）を使いません。ほかの市のしくみは処理券（シール）の買い方へ。

出し方

  • 収集日の当日に、1階（地上）のすぐ積み込める場所に出します。
  • 品物ごとに「受付番号」を書いた紙を必ず貼ります。貼っていないと収集を見合わせることがあります。
  • 家の中からの運び出しはしません。運び出しが必要なときは、市の許可業者に頼むか、運び出しだけをする事業所を市に紹介してもらえます（どちらも有料）。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • パソコン、ディスプレイ
  • 石・土・コンクリート、タイヤ、消火器、ガソリン・灯油など市の施設で処理できない物（収集・処理ができないもの）
  • 事業活動で出たごみ
  • 引越しなどで一度にたくさん出るごみ（集積所には出せません）

家電4品目は、市では収集も受け入れもしません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。市のページにも近くの指定引取場所が載っています（家電リサイクル法対象品目の処分方法）。

急ぐときは奥富環境センターへ持ち込む

引越しなどで一度にたくさん出るごみは、集積所には出せません。環境センターに自分で持ち込むか、市の許可業者に有料で頼みます。引越し業者には収集運搬の許可がないため、処分を頼むことはできません（引っ越しごみなどの一時多量ごみの出し方）。

  • 場所：奥富環境センター（狭山市大字上奥富897番地1、04-2953-2831）
  • 予約：要りません。
  • 受付：月〜金曜 8:30〜11:30、13:00〜15:30。土曜 8:30〜11:30。日曜・祝日・振替休日・年末年始は休み。
  • 料金の目安：家庭のごみは50kg未満は無料。50kg以上は、超えた分だけでなく全体の重さに10kgごとに90円（例：60kgで540円）。スプリング入りベッドマットレスは1点1,000円を足します。
  • 持ち物と決まり：持ち込めるのは原則、ごみを出す本人か同居の家族です。住所を確かめるため本人確認書類を見せることがあります。集積所に出すときと同じように分けて持ち込み、荷下ろしは自分で行います。狭山市の外で出たごみは受け付けません。
  • 布団・じゅうたん：稲荷山環境センター（04-2954-9062）へ持ち込みます。もやすごみが多いときもこちらです。

狭山市に引っ越してきた人へ

狭山市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しなどで一時的にたくさん出るごみは集積所に出せず、環境センターに持ち込むか、市の許可業者に有料で頼みます。
  • 引越し業者には収集運搬の許可がないため、ごみの処分を頼むことはできません。
  • 粗大ごみの予約収集で市外へ引っ越す場合は、収集に立ち会いが必要です。
  • 奥富環境センターに持ち込めるのは原則ごみを出す本人か同居の家族で、住所を確かめるため本人確認書類を見せることがあります。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。狭山市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 多い分は、環境センターへ持ち込む
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

狭山市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、狭山市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
