豊中市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、豊中市の公式ページをもとにまとめました。

2026年10月30日に豊中市の公式ページで確認・料金や日数は目安です

豊中市の粗大ごみは、品目ごとに400円・900円・1,800円・2,700円の手数料がかかり、収集は地域ごとに月1回です。電話の締め切りは収集日の7日前、インターネットは14日前なので、引越しが決まったら早めに申し込みましょう（豊中市の公式ページより）。

豊中市のポイント
  • 対象：最大の辺か径が30cm以上の電気機械器具と、市指定ごみ袋に入らない大きな物
  • 料金：品目ごとに400円・900円・1,800円・2,700円。粗大ごみ処理券（400円券・900円券）を組み合わせて払う
  • 申し込み：粗大ごみ受付センター（電話）、インターネット・LINE（24時間）。1回5点まで
  • 締め切り：電話は収集日の7日前、インターネットは14日前まで（3か月前から受付）
  • 急ぐとき：予約して豊中市伊丹市クリーンランドへ持ち込める（10kgごとに105円）

申し込み方法

  • 電話：豊中市 粗大ごみ受付センター 0570-666-861（つながらないときは06-6486-0530）。月曜〜金曜の9:00〜17:15、祝日も受付。休日明けや午前中はつながりにくいことがあります。
  • インターネット（24時間）：豊中市 粗大ごみインターネット受付。サイズの確認ができないため、申し込める品目に限りがあります。
  • LINE：豊中市LINE公式アカウントの「粗大ごみ・臨時ごみ持ち込み予約」から「粗大ごみ予約」へ。
  • ファクス：0570-666-725（聴覚・言語に障害のある人、外国人の人向け。日本語のみ）

受付は収集日の3か月前からです。1回に申し込めるのは5点までで、申し込みが集中すると翌月にまわることがあります。

出し方

  • 収集日の朝8時30分までに、申し込みのときに確かめた場所に出します。
  • 処理券に「受付番号」と「収集日」を書いて、申し込んだ品目に貼ります。
  • くわしくは市の「粗大ごみの出し方」（PDF）へ。
  • まだ使える物は、市が連携するジモティースポット豊中服部天神店（服部寿町2丁目4-10）に持ち込む方法もあります。手数料はかかりません。

出せない物と家電4品目

  • エアコン、テレビ（液晶を含む）、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • ブロック・がれき類、石・土・砂、太さ15cm以上の木の根・幹など収集や処理が難しい物
  • 折りたたむと市指定ごみ袋に入るホットカーペットや電気毛布は、粗大ごみではありません

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ運びます（指定引取場所の検索・料金の目安）。市の案内に載っている市内の指定引取場所は次のとおりです。

急ぐときはクリーンランドへ持ち込む

  • 場所：豊中市伊丹市クリーンランド。豊中市・伊丹市から出た一般廃棄物だけ受け付けます。
  • 予約：必要です。予約受付専用電話 06-6841-4498（月曜〜土曜の9:00〜17:00、祝日も受付）。希望日の7日前から当日の午前中まで予約できます（土曜午前の持ち込みは前日まで）。
  • 搬入時間：月曜〜金曜は14:00〜16:30、土曜は10:00〜16:00（12:00〜12:45を除く）。
  • 料金：ごみの重さ10kgごとに105円。
  • 可燃ごみと不燃ごみ（粗大ごみを含む）は分けます。家電4品目やパソコンは持ち込めません。

豊中市に引っ越してきた人へ

豊中市の公式ページでは、引越しや転入について次のように案内しています（2026年10月30日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しや片付けで多量に出るごみは「臨時ごみ」として粗大ごみ受付センターに電話で申し込みます（インターネット不可、収集の3か月前から3日前まで）。
  • 臨時ごみの粗大ごみは1点670円・1,350円・2,700円・4,050円で、収集の日に立ち会って現金で払います。処理券は使えません。
  • 豊中市伊丹市クリーンランドに持ち込めるのは、豊中市・伊丹市から出た一般廃棄物だけです。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。豊中市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。家庭のごみを運べるのは市区と市区の許可業者だけです（ぼったくりの実例と見分け方）。

豊中市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、豊中市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
