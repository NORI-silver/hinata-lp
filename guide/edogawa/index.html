江戸川区の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、江戸川区の公式ページをもとにまとめました。

2026年10月31日に江戸川区の公式ページで確認・料金や日数は目安です

江戸川区の粗大ごみは、一辺（最大辺）が30cm以上の物が対象です。日曜・祝日も収集していて、北部・南部の2か所の持込施設へ自分で運ぶと、収集より安くなります。申し込み順なので、混むと希望の日に取れないことがあります（江戸川区の公式ページより）。

江戸川区のポイント
  • 対象：一辺（最大辺）が30cm以上の物
  • 申し込み：インターネット・チャットボット（24時間）、電話（月〜土 8時〜19時）
  • 料金：収集400円〜3,200円。持ち込みは割安（例：自転車は収集900円、持ち込み400円）
  • 収集：日曜・祝日も収集（年末年始を除く）。朝8時までに出す
  • 持ち込み：北部（篠崎町）・南部（西葛西）。年中無休、1回10個まで・年度内3回まで（要申込）

申し込み方法

  • インターネット（24時間）：江戸川区 粗大ごみ受付センター。申し込みごとにメールアドレスの登録が必要です。
  • チャットボット（24時間）：ごみ分別・粗大ごみチャットボット。いちばん早い収集日・持込日や手数料も調べられます。
  • 電話：粗大ごみ受付センター 03-6744-5700（月〜土 8時〜19時、年末年始を除く）

  • 有料粗大ごみ処理券A（200円）・B（300円）を、収集日・持込日までに区の取扱所で買います。江戸川区の処理券しか使えません。
  • 券が貼られていない、他区の券、料金が足りないときは、収集も持ち込みもできません。

出し方

  • 収集日の朝8時までに、玄関など（集合住宅は1階の置き場など）に出します。収集はおおむね8時〜15時30分です。
  • ごみの集積所には出しません。カギがかかる置き場なら、開け閉めを事前に確かめておきます。
  • 処理券に収集日と氏名（または受付番号）を書いて貼ります。出し忘れたら申し込み直しです。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）、パソコン
  • 自動車・オートバイ・タイヤ、ピアノ、耐火金庫、消火器、ガスボンベ、蓄電池など
  • 長さがおおむね1m80cm、太さ30cm、重さ50kgを超える物
  • 事業活動で出た物

家電4品目は区では回収しません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ運びます（指定引取場所の検索・料金の目安）。

急ぐときは持込施設へ運ぶ

  • 場所：北部粗大ごみ持込施設（篠崎町2丁目62番17号、京葉道路江戸川大橋付近）、南部粗大ごみ持込施設（西葛西1丁目10番16号、区立行船公園付近）
  • 年中無休（年末年始を除く）、9時〜15時30分。申し込みのときに決めた日時に、処理券を貼って持ち込みます。
  • 区民だけ。1世帯1回10個まで、年度内3回まで。同じ日に2回は持ち込めません。
  • 本人か同居の家族だけ。運転免許証やマイナンバーカードなど本人確認書類が必要です。

引越しなどで45リットル袋3袋を超えるごみを臨時に出すときは有料です（45リットル袋1袋300円、70リットル袋1袋500円）。お住まいの地区の清掃事務所に相談します。

出典：江戸川区 粗大ごみ、江戸川区 ごみを大量に出す場合（2026年10月30日に確認）

江戸川区に引っ越してきた人へ

江戸川区の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 粗大ごみの運び出しサービスは、引越しやリフォームなどによる申し込みは受け付けていません。
  • 引越しなどで45リットル袋3袋を超えるごみを臨時に出すときは有料（45リットル袋1袋300円、70リットル袋1袋500円）で、管轄の清掃事務所に相談します。
  • 持ち込みは区民だけで、本人か同居の家族が本人確認書類を持って行きます。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。江戸川区の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

江戸川区の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、江戸川区の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
