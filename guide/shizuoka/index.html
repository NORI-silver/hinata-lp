静岡市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、静岡市の公式ページをもとにまとめました。

2026年10月30日に静岡市の公式ページで確認・料金や日数は目安です

静岡市では、粗大ごみは「不燃・粗大ごみ」として地域ごとに月1回、申し込んだ家を回る戸別収集です。締め切りは収集日の1週間前なので、引越しが決まったらすぐに申し込みましょう（静岡市の公式ページより。葵区の安倍6地区は申し込み不要の集積所収集です）。

静岡市のポイント
  • 対象：不燃ごみと粗大ごみをまとめて「不燃・粗大ごみ」として収集
  • 申し込み：電話（不燃・粗大ごみ受付センター）。2回目からはインターネットも可
  • 締め切り：収集日の1週間前まで。収集は地域ごとに月1回
  • 1回に出せるのは7点まで。1点ごとに「氏名」と「不用」を書く
  • 急ぐとき：引越しなどで多いときは、清掃工場に問い合わせてから持ち込める

申し込み方法

  • 電話：不燃・粗大ごみ受付センター 0120-532-471（月〜金 9:00〜19:00、祝日も受付。年末年始は休み）。フリーダイヤルが使えないときは 054-292-6700（有料）。受付が始まった直後は混みます。
  • インターネット（2回目から）：静岡市 不燃・粗大ごみインターネット受付。申し込んでからおよそ2日以内に「受付完了メール」が届きます。

初めて申し込む人、前回から住所が変わった人は電話で申し込みます。引越してきたばかりの人や、市内で引越す人も電話です。品目の入れ替え・追加は収集日の2営業日前まで、減らす・取り消すのは1営業日前までです（土日は営業日に数えません）。

料金

不燃・粗大ごみの戸別収集の手数料は、市の不燃・粗大ごみのページには書かれていませんでした。申し込みのときに市の公式ページか受付センターで確かめてください。

出し方

  • 1回に出せるのは7点までです。指定袋に入る物は1袋で1点と数えます。蛍光灯・乾電池・ライター・水銀の体温計や温度計は点数に入りません。
  • 7点を超えるときは、翌月以降に申し込むか、清掃工場へ持ち込みます。
  • 出す物1点ごとに、よく見える場所に「氏名」と「不用」を書きます。
  • ベッドやタンスなど大きな物は、申し込む前にだいたいの大きさを測っておきます。
  • 収集日は市のごみ収集日の検索で確かめられます。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）は、不燃・粗大ごみとしては出せません。
  • 市で収集も処理もできない物（処理困難物）は、買ったお店や専門の処理業者に相談します。一覧は市では収集・処理できないごみへ。
  • 充電式電池が取り外しにくい電化製品は、電話で申し込みます。

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ運びます（指定引取場所の検索・料金の目安）。

急ぐときは清掃工場へ持ち込む

施設場所電話
西ケ谷清掃工場葵区西ケ谷553番地054-296-0054
沼上清掃工場葵区南沼上1224番地054-262-4015
  • 受け入れは月〜金 8:30〜12:00・13:00〜16:00、土曜 8:30〜12:00（祝日も受け入れ）。日曜は休みです。
  • 引越しなどで多く出たごみは、西ケ谷か沼上の清掃工場に問い合わせてから持ち込みます。市は、少しだけの持ち込みは控えて戸別収集を使うよう呼びかけています。
  • 持ち込むときは身分証などで本人確認があり、自分で分別します。静岡市外のごみは持ち込めません。
  • 清水ごみ受付センター（清水区八坂町）は、土曜は不燃・粗大ごみを受け付けていません。
  • 家庭ごみの持ち込みの料金は、市の持ち込みのページか各清掃工場で確認してください。
  • リユース：まだ使える物は、ジモティースポット静岡（実証実験中）も案内されています。

出典：静岡市 不燃・粗大ごみの出し方・清掃工場等への家庭ごみの持ち込み

静岡市に引っ越してきた人へ

前の家から持ってきた家具などを静岡市で粗大ごみに出すときの決まりは、静岡市の公式ページには特に書かれていませんでした（2026年10月30日確認）。静岡市の家庭のごみとして申し込むので、申し込むときに「引越しで持ってきた物」と伝えて確かめると安心です。

  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。静岡市の分け方に従って出します。
  • 初めて申し込む人や、前回から住所が変わった人は、インターネットではなく電話（0120-532-471）で申し込みます。
  • 引越しなどで多く出たごみは、西ケ谷清掃工場か沼上清掃工場に問い合わせてから持ち込むよう、市が案内しています（静岡市 清掃工場等への家庭ごみの持ち込み）。
  • 持ち込みでは身分証などで本人確認があり、静岡市外のごみは持ち込めません。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。家庭のごみを運べるのは市区と市区の許可業者だけです（ぼったくりの実例と見分け方）。

静岡市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、静岡市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
