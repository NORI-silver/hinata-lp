ソファの捨て方・処分方法（70市区の料金）

ソファを粗大ごみで出すときの料金を市区ごとに比べ、持ち込み・買取など、ほかの手放し方もまとめました。

2026年10月30〜31日に各市区の公式ページで確認・料金や日数は目安です

ソファは粗大ごみで出せる？

ソファは大きさ（1人掛け・2人掛け以上）やスプリングの有無で料金が変わる市区が多く、粗大ごみの中では高めの品目です。玄関や階段から出せるか、収集の日に家の前まで運べるかも先に考えておきます。

まだきれいなソファは、出張買取（キャンセル無料をはっきり書いているチェーン）に見てもらうと、処分代がかからないことがあります。値段がつかなければ断って、市区の粗大ごみに切り替えます。

ソファを手放す4つの方法

  1. 市区の粗大ごみ：申し込んで、処理券（シール）を貼り、指定の日に出します（処理券の買い方・貼り方）。
  2. 自分で持ち込む：車があれば、収集より早く・安く出せる市区もあります（市区ごとの持ち込み先）。
  3. 買取・譲る：まだ使える物は、出張査定とキャンセルが無料のチェーンに見てもらうか、市区が案内するリユース（ジモティーとの連携など）を使います。
  4. 許可業者に頼む：家のごみを運べるのは市区と市区の許可業者だけです。「無料で回収」の巡回業者には頼まないでください（ぼったくりの実例）。
