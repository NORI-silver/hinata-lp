八戸市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、八戸市の公式ページをもとにまとめました。

2026年10月31日に八戸市の公式ページで確認・料金や日数は目安です

八戸市の粗大ごみは、1点ごとに520円の処理券を貼って出します。申し込みは粗大ごみ予約受付センターへの電話で、収集まで約1週間かかります。引越しが決まったら余裕をもって申し込みましょう（八戸市の公式ページより）。

八戸市のポイント
  • 対象の目安：たんす・ベッド・自転車などの大型の物、バット・傘・スキー板などの長い物、45リットルの袋に入らない物（ファンヒーター・電子レンジ・ふとんなど）
  • 料金：八戸市粗大ごみ処理券 1枚520円。原則1点に1枚
  • 申し込み：電話（平日 8:30〜16:30）。1回5点まで、大人2人で運べる重さまで
  • 収集まで：約1週間。収集日の朝8時までに、申し込みで伝えた場所に出す
  • 急ぐとき：八戸リサイクルプラザへ持ち込める（家庭ごみは50kgごとに150円）

申し込み方法

  • 電話：八戸市 粗大ごみ予約受付センター 0178-70-7155（月〜金曜 8:30〜16:30、土日・祝日・年末年始は休み）
  • ファクス：0178-70-7160

名前・収集する場所の住所・粗大ごみの種類を伝えます。1回の収集で5点まで、大人2人で運べる重さの物までです。インターネットの受付は、市のページで八戸ごみ収集アプリから2026年11月にはじめる予定と案内されています。始まったかどうかは市のページで確かめてください。

料金は目安です。2026年10月31日に八戸市 粗大ごみ（家庭から出るもの）で確認。処理券は原則1点に1枚（520円）で、ふとんは2枚、座布団・傘・ゴルフクラブ・釣りざおは5本、物干しざお・スノーダンプは2本で1枚です。ベッドは枠とマットレスで2枚、ソファーセットは1脚ごと、2段ベッドは1段ごとに1枚要ります。

  • 八戸市粗大ごみ処理券は、八戸市指定ごみ袋の取扱店で買います（取扱店の一覧・処理券（シール）の買い方）。
  • 処理券に名前を書いて、品物に貼ります。

出し方

  • 収集日の朝8時までに、申し込みのときに伝えた場所（玄関の前など）に出します。
  • ごみ集積所には出しません。
  • 木のベッドの枠を50cm以下に分ければ燃やせるごみ、金属の枠なら燃やせないごみとして出せます。長い物も、指定袋に入るよう折りたためれば材料に合わせて燃やせる・燃やせないごみで出せます。
  • まだ使える家具・自転車は、事前に連絡して八戸リサイクルプラザに無料で引き取ってもらう方法もあります（市民に抽選で譲られます）。

出せない物と家電4品目

  • テレビ、エアコン、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象。市の家電4品目のページ）
  • 大人2人で運べない重さの物
  • 引越しなどでたくさん出るごみ（ごみ集積所に出さず、自分で施設へ運ぶか、一般廃棄物の許可業者に頼みます）

家電4品目は、市では収集しません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。

急ぐときは八戸リサイクルプラザへ持ち込む

  • 場所：八戸リサイクルプラザ（八戸市大字櫛引字山田山1-1、0178-70-2396）。粗大ごみと燃やせないごみを受け入れます。引越しで一度にたくさん出たごみも持ち込めます。
  • 受付時間：月〜金曜 9:00〜12:00、13:00〜17:00（祝日・年末年始は休み）。受け入れ日は八戸地域広域市町村圏事務組合のページで確かめてから行きます。
  • 料金の目安：家庭ごみは50kgごとに150円。重さで決まるので、処理券は要りません。荷下ろしは自分で行います。
  • 持ち込めない物：家電4品目、パソコン、タイヤ・ホイール、ピアノ、液体の入った物、電池・蛍光管などの有害ごみ、ガスボンベ・消火器・塗料などの危険物、直径15cm・長さ150cmを超える木やパイプなど。
  • 対象：八戸市・南部町（旧福地村の地域）・階上町で出た家庭ごみ。
  • ふとん・じゅうたん：八戸清掃工場（八戸市大字櫛引字取揚石1-1、0178-27-1351）へ。受付は月〜金曜 9:00〜12:00、13:00〜17:00、家庭ごみは50kgごとに150円で現金払いです。
  • 予約の要否は公式ページに書かれていません。持ち込む前に施設へ確認してください。

自分で運べないときは、一般廃棄物の許可業者に頼みます（市の引っ越しごみ・大量に出るごみのページ）。持ち込みの準備と持ち物

八戸市に引っ越してきた人へ

八戸市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引っ越しなどで大量に出るごみはごみ集積所に出さず、自分で八戸清掃工場・八戸リサイクルプラザへ運ぶか、一般廃棄物の許可業者に頼みます。
  • 八戸リサイクルプラザは、引越しなどで一時的にたくさん出た家庭の燃やせないごみ・粗大ごみも受け入れます（八戸市・南部町の旧福地村地域・階上町が対象）。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。八戸市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 受付に電話して、早い収集日がないか聞く
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

八戸市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、処分代がかからず値段がつくこともあるので、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらい、値段がつかなければ断って八戸市の粗大ごみに切り替えます（どのお店とも提携していません）。

セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどの買取チェーンが出張買取をしています。
