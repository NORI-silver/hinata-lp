多摩市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、多摩市の公式ページをもとにまとめました。

2026年10月31日に多摩市の公式ページで確認・料金や日数は目安です

多摩市では、有料指定袋に入らない物か、重さが5kg以上の物が粗大ごみです。1回に出せるのは3点までですが、引越しする人は最後の週に限り6点まで申し込めます。急ぐときは清掃工場へ申込制で持ち込めます（多摩市の公式ページより）。

多摩市のポイント
  • 対象：有料指定袋に入らない物、または重さ5kg以上の物
  • 申し込み：電子申請（クレジットカード・PayPay払いもできる）、粗大ごみ専用ダイヤル（平日）
  • 料金：品目ごとに200円〜（処理券は200円券と400円券）
  • 点数：1回3点まで。引越しする人は最後の週だけ6点まで
  • 収集：収集日の朝8時までに指定の場所へ。電子申請から収集までは中3日ほど
  • 持ち込み：清掃工場へ申込制、10kgごとに250円（現金のみ）

申し込み方法

  • インターネット：多摩市 粗大ごみ電子申請。市内に住み、家庭から出る粗大ごみを出す人が対象です。手数料をクレジットカードかPayPayで払えます。申請から収集日までは中3日ほどかかります（申し込み方法のページ）。
  • 電話：多摩市 粗大ごみ専用ダイヤル 042-375-9713（月〜金曜 8:30〜17:00、祝日・年末年始は休み）
  • ファクス：聴覚や言語に障がいのある人の運び出しサービスの申し込みは 042-356-3919。

電話の申し込みは、収集日の2週間前から受け付け、締め切りは収集日の前日15時です（月曜に収集する地区は前の週の金曜15時。前日が祝日なら、その前の平日15時）。収集日は申し込みのときに案内されます。

  • 電話で申し込んだ人は、粗大ごみ処理券（200円券・400円券）を取扱店で買い、組み合わせて貼ります（取扱店のページ）。買い方は処理券（シール）の買い方へ。

  • せん定枝・落ち葉・刈り草は無料です。「不要品」と書いた紙に名前を書いて貼ります。

出し方

  • 処理券に名前を書いて、品物の目立つところに直接貼ります。
  • 収集日の前の日の夜から、当日の朝8時までに、指定された場所に出します。できるだけ当日の朝に出してください。
  • 1回に出せるのは、有料・無料あわせて3点までです。引越しする人は、最後の週に限り6点まで申し込めます。
  • 65歳以上だけの世帯などで指定場所まで運べないときは、粗大ごみ運び出しサービスを相談できます。

出せない物と家電4品目

  • エアコン、テレビ、洗濯機（衣類乾燥機）、冷蔵庫・冷凍庫（家電リサイクル法の対象）
  • パソコン（パソコンのリサイクル）
  • 原付バイク・オートバイ（オートバイのリサイクル）

家電4品目は、市では収集しません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます。お店がわからないときは、市が載せている収集運搬の許可業者に頼めます（市の家電リサイクルのページ・指定引取場所の検索・料金の目安）。

急ぐときは清掃工場へ持ち込む（申込制）

  • 持ち込み先：多摩ニュータウン環境組合の清掃工場（市のページから組合のサイトへ）。
  • 申し込み：必要です。粗大ごみ専用ダイヤル 042-375-9713（月〜金曜 8:30〜17:00）。申し込んだ物以外は持ち込めません。平日は当日の申し込みもできますが、16時30分までに工場に着く必要があります。
  • 受付時間：月〜金曜（祝日・年末年始を除く）と毎月第4日曜日の 8:30〜11:30、13:00〜16:30。第4日曜日の分は、その月の1日から直前の金曜日まで午前・午後に分けて受け付けます。1日に受け入れる台数に上限があります。
  • 料金：10kgごとに250円（5kg未満は切り捨て、5kg以上は10kgに切り上げ。全体で10kg未満でも10kg分）。車ごと量り、現金のみで払います。処理券は使えません。
  • 持ち物と決まり：市内に住み、自分で運べる人が対象で、運転免許証などで住所を確かめます。ごみは自分で下ろすので、手袋や汚れてもよい服を用意します。家電4品目・パソコン・消火器・タイヤ・バッテリーなどは持ち込めません。

くわしい準備は持ち込みの準備と持ち物へ。

多摩市に引っ越してきた人へ

多摩市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 粗大ごみは1回3点までですが、引越しをする人は最後の週に限り6点まで申し込めます。
  • 清掃工場への持ち込みは申込制で、市内に住む人が自分で運ぶ場合に限られ、運転免許証などで住所を確認します。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。多摩市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

多摩市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、多摩市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
