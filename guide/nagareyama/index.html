流山市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、流山市の公式ページをもとにまとめました。

2026年10月31日に流山市の公式ページで確認・料金や日数は目安です

流山市の粗大ごみは、家の前まで取りに来てもらう戸別収集で、手数料は1点1,100円の一律です。インターネットで申し込むと、収集はいちばん早くて申し込みの10日後です。急ぐときはクリーンセンターへ予約なしで持ち込めます（流山市の公式ページより）。

流山市のポイント
  • 対象の目安：木製で一辺50cm以上の物、電気製品・金属・プラスチックなどで一辺1m以上の物、大きさに関係なく粗大ごみになる「指定品目」
  • 料金：1点（1組）1,100円の一律。処理券も1,100円券
  • 申し込み：インターネット（24時間）、電話（クリーンセンター）
  • 収集まで：インターネットの場合、いちばん早くて申し込みの10日後。収集日の朝8時30分までに出す
  • 急ぐとき：流山市クリーンセンターへ予約なしで持ち込める（10kgごとに300円）

申し込み方法

  • インターネット（24時間）：流山市 粗大ごみインターネット受付。仮の申し込みのあと、次の開庁日にクリーンセンターが本申し込みにして、確認のメールが届きます。利用者登録をしておくと便利です。
  • 電話：流山市クリーンセンター 04-7157-7411（開庁日の9:00〜16:30）

インターネットで申し込んだときの収集日は、いちばん早くて申し込みの10日後です。手数料は原則として返しません。申し込みの手順は市の申し込み手順（PDF）にあります。

料金の目安と払い方

品目料金
粗大ごみ（ソファー・たんす・自転車など）1点1,100円
布団類・ふすま・障子（それぞれ4枚までで1点）1,100円
ベッド（枠とマットレスで1点）1,100円

料金は目安です。2026年10月31日に流山市 粗大ごみ指定品目で確認。1点（1組）ごとに1,100円（税込み）です。

  • 電話で申し込んだ人は、「粗大ごみ処理券」（1枚1,100円）を1点につき1枚、取扱店で買います（取扱店の一覧）。
  • インターネットで申し込んだ人は、クレジットカード・PayPayでも払えます。キャッシュレスで払えるのは収集日の3日前までで、それより後は処理券を買います。キャッシュレスでは領収書が出ないので、領収書が要る人は処理券を買ってください。

処理券（シール）の買い方

出し方

  • 収集日の朝8時30分までに、玄関先や駐車場など、家の外の指定された場所に出します。立ち会いは要りません。
  • 家の中や2階以上に置いたままの物は収集しません。自分で運び出せないときは、市の許可を受けた一般廃棄物収集運搬業者に頼みます（料金は業者ごとに違います。許可業者の一覧）。
  • 処理券には受付番号を書き、見えるところに貼ります。キャッシュレスで払った人は、印刷した券か、受付番号と収集日を書いた紙をテープでしっかり貼ります。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • パソコン（パソコンの出し方）

家電4品目は、市では収集も処分もしません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（市の家電4品目のページ・指定引取場所の検索・料金の目安）。

急ぐときは流山市クリーンセンターへ持ち込む

  • 場所：流山市クリーンセンター（流山市下花輪191番地、04-7157-7411）
  • 予約：要りません。
  • 受付：月〜土曜（日曜は休み）の8:30〜11:40と13:00〜16:15。日曜以外の祝日も受け付けます。年末年始はクリーンセンターに確かめてください。
  • 料金の目安：10kgごとに300円（税込み）。車ごと量って、降ろした分の重さで払います。10kg未満の端数は四捨五入で、全体が10kg未満なら10kgとして計算します（例：50kgで1,500円）。集積所に出せるごみも、持ち込むと有料です。
  • 持ち物：流山市の住所が分かる運転免許証。住所を変えていないときや、市外に住む家族が運ぶときは、流山市の住所が書かれた公共料金の領収書なども持っていきます。

流山市に引っ越してきた人へ

流山市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • クリーンセンターへの持ち込みでは、運転免許証で流山市の住所を確かめます。
  • 免許証の住所を変えていないときや市外の家族が運ぶときは、流山市の住所が書かれた公共料金の領収書などが必要です。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。流山市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

流山市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、処分代がかからず値段がつくこともあるので、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらい、値段がつかなければ断って流山市の粗大ごみに切り替えます（どのお店とも提携していません）。

セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどの買取チェーンが出張買取をしています。
