岸和田市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、岸和田市の公式ページをもとにまとめました。

2026年10月31日に岸和田市の公式ページで確認・料金や日数は目安です

岸和田市の粗大ごみは、電話で申し込むしくみです。手数料は1個500円か1,000円の2段階で、「粗大ごみ処理券」（500円券の1種類）を貼って出します。申し込みは平日だけなので、引越しが決まったら早めに電話しましょう（岸和田市の公式ページより）。

岸和田市のポイント
  • 申し込み：粗大ごみ申し込み専用電話（月〜金曜 9:00〜17:30）。インターネットの申し込み先は市のページに載っていない
  • 料金：1個500円（3辺の合計が3m以内、または45リットル袋1杯分の量）、それより大きい物は1,000円
  • 支払い：粗大ごみ処理券（500円券）を、案内された金額の分だけ買って貼る
  • 出し方：収集日の朝9時までに、自宅前や指定された場所へ。立ち会いは要らない
  • 多量のごみ：引越しなどで一度にたくさん出るときは、許可業者に頼むか、可燃ごみ・金属ごみを岸和田貝塚クリーンセンターへ持ち込める

申し込み方法

  • 電話：粗大ごみ申し込み専用電話 072-433-0053（月〜金曜 9:00〜17:30、土日・祝日・年末年始は休み）

住所・名前・電話番号・品目・数量を伝えると、手数料と収集日を教えてもらえます。月曜日と祝日の翌日は混み合うので、つながらないときは時間をおいてかけ直してください。インターネットでの申し込み先は、2026年10月31日に見た市のページには載っていませんでした。

料金の目安と払い方

大きさ料金
45リットル袋1杯分の量（1個）500円
3辺（縦・横・高さ）の合計が3m以内の物（1個）500円
3辺の合計が3mを超える物（1個）1,000円

料金は目安です。2026年10月31日に岸和田市 ごみの出し方と分け方で確認。品目ごとの金額の一覧は載っていないため、申し込みのときに確かめてください。

  • 申し込みのときに案内された金額の分だけ「粗大ごみ処理券」（500円券の1種類）を、近くのごみ処理券取扱所で買います。
  • 他の市の処理券は使えません。払い戻し・再発行もできません。

処理券の買い方の全体は処理券（シール）の買い方にまとめています。

出し方

  • 処理券の「収集日」の欄に収集日を書き、品物に貼ります。
  • 収集日の朝9時までに、自宅前や指定された場所に出します。立ち会いは要りません。
  • 介助・介護が要る65歳以上だけの世帯や、援助が要る障がいのある人だけの世帯は「ふれあい収集」を申し込めます（ファクス 072-436-0418 でも可）。引越しや部屋の片づけなどの多量ごみは対象外です。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • パソコン、バイク・原動機付自転車
  • タイヤ、バッテリー、消火器、建築廃材、危険な物、事業活動で出たごみ、処理が難しい物

家電4品目は粗大ごみでは出せません。買い替えるお店・買ったお店に引き取ってもらうか、リサイクル料金を払って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。市も、リサイクル料金とは別に1台2,000円の運搬手数料で収集運搬を受けています（申し込みは 072-433-0053）。

多いときは岸和田貝塚クリーンセンターへ持ち込む

  • 持ち込める物：家庭から臨時に多量に出る可燃ごみ・金属ごみ。粗大ごみそのものの持ち込みについては、市のページに書かれていません。
  • 持ち込み先：岸和田貝塚クリーンセンター（岸和田市貝塚市清掃施設組合、072-436-5389）。有料です。
  • 受付時間・料金・予約：市のページには載っておらず、組合のホームページで確かめるよう案内されています。持ち込む前に組合へ確認してください。
  • 周辺の道路が混み、長く待つことがあります。
  • 自分で運べないときは、市の許可業者に有料で収集を頼めます（業者の一覧は市のページ）。

持ち込む前の準備は持ち込みの準備と持ち物にまとめています。

岸和田市に引っ越してきた人へ

岸和田市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しなどで出る多量のごみや臨時のごみは、市の許可業者に頼むこともできると市が案内しています。
  • 家庭から臨時に多量に出る可燃ごみ・金属ごみは、岸和田貝塚クリーンセンターへ有料で直接持ち込めます。
  • ふれあい収集（高齢者・障がいのある人の世帯向け）は、引越しや部屋の片づけなどの多量ごみには使えません。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。岸和田市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 受付に電話して、早い収集日がないか聞く
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 可燃ごみ・金属ごみが多いときは岸和田貝塚クリーンセンターへ（粗大ごみを持ち込めるかは組合に確認）
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

岸和田市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、処分代がかからず値段がつくこともあるので、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらい、値段がつかなければ断って岸和田市の粗大ごみに切り替えます（どのお店とも提携していません）。

セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどの買取チェーンが出張買取をしています。
