町田市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、町田市の公式ページをもとにまとめました。

2026年10月30日に町田市の公式ページで確認・料金や日数は目安です

町田市では、指定収集袋に入らない物か、1つで10kgを超える物が粗大ごみです。予約は電話とインターネットを合わせた先着順で、混み合うことがあるので、引越しが決まったら早めに予約しましょう（町田市の公式ページより）。

町田市のポイント
  • 対象：指定収集袋に入らない物、または1つの重さが10kgを超える物
  • 申し込み：粗大ごみ受付専用ダイヤル（月〜土曜）か、まちだエコライフ推進公社のサイトから予約。先着順
  • 支払い：粗大ごみ処理券（400円券の1種類）を、案内された枚数だけ貼る
  • 収集：収集日の朝8時30分までに、指定された場所に出す
  • 持ち込み：町田市バイオエネルギーセンターへ予約制・10kgごとに250円（現金のみ）

申し込み方法

  • 電話：粗大ごみ受付専用ダイヤル 042-797-1651（月〜土曜 8:30〜17:00、日曜・祝日・年末年始は休み）。月・火曜と、毎日12時〜13時は混み合います。
  • インターネット：まちだエコライフ推進公社のサイトから予約できます。

受付と収集は、市の委託でまちだエコライフ推進公社が行っています。何日前までという締め切りは市のページに書かれていないので、早めに予約してください。品目や出し方がわからないときも、受付専用ダイヤルで聞けます。

料金と払い方

手数料は品目ごとに決まっていて、粗大ごみ処理券（400円券）を、予約のときに案内された枚数だけ買って貼ります。品目ごとの金額の一覧は市のページに載っていないため、予約のとき（042-797-1651）に確かめてください。処理券は市内のスーパー・ドラッグストア・コンビニなどの取扱店で買えます（取扱店のページ）。買ったあとの払い戻しはできません。

出し方

  • 処理券の裏に受付番号と収集日を書き、品物の見やすいところにしっかり貼ります。一度貼ると貼り直せません。
  • 収集日の朝8時30分までに、予約のときに案内された場所に出します。
  • 処理券が足りない、受付番号が書いていない、予約していない品物がまざっている、のどれかだと収集されません。

出せない物と家電4品目

  • 家電リサイクル法の対象品目（テレビ、冷蔵庫、冷凍庫、洗濯機、衣類乾燥機、エアコン）
  • パソコン
  • 市で処理できない物（市では処理できない家庭ごみへ）

家電4品目は、市では収集しません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ運びます（指定引取場所の検索・料金の目安）。

急ぐときはバイオエネルギーセンターへ持ち込む

  • 場所：町田市バイオエネルギーセンターの清掃工場（町田市下小山田町3160番地）。旧清掃工場の入口からは入れません。
  • 予約：必要です。インターネットか粗大ごみ受付専用ダイヤル（042-797-1651）で、当日から2か月先まで予約できます。当日に持ち込むときは、午前の分は10時30分まで、午後の分は15時までに予約します（枠が埋まると締め切り）。
  • 受付時間：月〜土曜の8:30〜11:30と13:00〜16:00（日曜・祝日・12月31日〜1月3日は休み）。
  • 料金：10kgごとに250円。入るときと出るときに車ごと量り、その差で計算します。現金のみで自動精算機で払い、処理券は使えません。
  • 持ち物と決まり：住所を確かめるため運転免許証などが必要です。出す人と運ぶ人が違うときは、出す人の直近の公共料金の請求書なども持っていきます。荷下ろしは原則自分で行います。指定収集袋に入るごみ・資源・有害ごみは持ち込めません。

引越しや遺品整理で一度にたくさん出るときは、市の許可業者に分別から収集までまとめて頼めます。先に市のごみ収集課（042-797-7111、月〜土曜 8:30〜17:00）で受付が必要で、業者に直接連絡しても頼めません（市の一時多量ごみのページ）。まだ使える物は、市と連携した「ジモティースポット町田」に無料で持ち込めます。

出典：町田市 粗大ごみの収集を希望する場合、町田市 粗大ごみを清掃工場へ持込む方へ

町田市に引っ越してきた人へ

町田市の公式ページでは、引越しや転入について次のように案内しています（2026年10月30日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しや遺品整理で一時的に多量に出るごみは、市のごみ収集課で事前受付をしたうえで、市の許可業者に分別から収集までまとめて依頼できます。
  • バイオエネルギーセンターへの持ち込みでは住所確認のため運転免許証などが必要で、運ぶ人が出す人と違うときは直近の公共料金の請求書なども必要です。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。町田市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。家庭のごみを運べるのは市区と市区の許可業者だけです（ぼったくりの実例と見分け方）。

町田市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、町田市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
