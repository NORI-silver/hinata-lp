立川市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、立川市の公式ページをもとにまとめました。

2026年10月30日に立川市の公式ページで確認・料金や日数は目安です

立川市の粗大ごみは、品目ごとのポイントを合計して料金が決まるしくみです。1〜3ポイントで300円が最低料金で、1回20ポイント（2,000円）まで出せます。収集日は申込日の7日後から選べるので、引越しが決まったら早めに申し込みましょう（立川市の公式ページより）。

立川市のポイント
  • 対象：市内の一般家庭で使っていた粗大ごみ。事業所のごみは収集しない
  • 料金：合計ポイントで300円〜2,000円（1回20ポイントまで）。処理券は1,000円券と300円券
  • 申し込み：インターネット（24時間）、粗大ごみ受付センターへ電話（平日）
  • 収集まで：申込日の7日後（混み具合で変わる）から2か月先までの日を選ぶ。収集日の朝8時までに出す
  • 急ぐとき：クリーンセンターたちむにぃ・総合リサイクルセンターへ予約なしで持ち込める（10kgにつき300円）

申し込み方法

  • インターネット（24時間）：立川市 粗大ごみ収集受付システム。メールアドレスを入れ、届いたメールのURLから氏名・住所・品目などを入力し、収集日を選びます（メンテナンス中は使えません）。追加・変更・取り消しは申込完了メールのURLからできます。
  • 電話：立川市粗大ごみ受付センター 042-531-5311（月〜金曜 9:00〜16:00、祝日・年末年始は休み）。休日明けと午前中はつながりにくくなります。品目の大きさと数を先に確かめておくとスムーズです。
  • ファクス：話すことや聞くことが不自由な方は、住所・氏名・ファクス番号・品目・大きさ・数量を書いて 042-531-5800 へ送れます。

土日・年末年始は収集日に選べません。品目の追加・変更は収集日の前日正午まで（前日が日曜・祝日のときは直前の開庁日）です。同じ世帯は、収集日から1か月以内に次の収集を頼めません。

料金の目安と払い方

品目ごとのポイントを合計し、1〜3ポイント300円、4〜6ポイント600円、7〜9ポイント900円、10ポイント1,000円……20ポイント2,000円、と決まります。下の表は、その品目を1点だけ出すときの料金です。

品目（ポイント）料金
テーブル・座卓・椅子（2ポイント）300円
電子レンジ・掃除機・扇風機（2ポイント）300円
自転車 22インチ以上（3ポイント）300円
ソファー（3ポイント）300円
学習机・机（3ポイント）300円
ベッド（3ポイント）300円
ソファーベッド・二〜三段ベッド（5ポイント）600円
電動アシスト自転車（5ポイント）600円

料金は目安です。2026年10月30日に立川市 粗大ごみの収集方法で確認。たとえばソファー（3）とベッド（3）を一緒に出すと6ポイントで600円です。ほかの品目はごみ分別辞典「ごみサク」か、たちかわごみ分別アプリで確かめられます。

  • 粗大ごみ処理券（紙）：1,000円券と300円券。申し込んだあとに市内の取扱店で買います（取扱店の一覧（PDF））。300円券は一度に3枚までで、1,000円券と組み合わせることがあります。払い戻しはできません。
  • オンライン決済：インターネットで申し込むときに選べます。クレジットカード（VISA、Mastercard、JCB、American Express、DINERS）かPayPay。店で買う処理券とは併用できません。払い戻しはできませんが、余った分は次のオンライン申込で使えます。
  • 生活保護受給世帯などは、申請すると手数料が減免されます。
  • 券の買い方のコツは処理券（シール）の買い方へ。

出し方

  • 収集日の朝8時までに、戸建ては玄関先、集合住宅は集積所などに出します。
  • 処理券に収集日・名前・品目名を書いて品物に貼ります。2枚以上のときは1枚ずつ別の品物に貼ります。自転車はサドルに貼ります。
  • オンライン決済の人は、収集日・予約番号（または名前）・品目を書いた紙か、申込時に出る「粗大ごみ収集用紙（貼り付け用）」を印刷して貼ります。
  • ベッド・物置・大型の室内遊具は必ず解体します。ふとん・カーペットは丸めてひもで結びます。
  • 市は家の中から運び出しません。難しいときは立川市シルバー人材センター羽衣ワークセンター（有料、042-523-5921、平日 8:30〜17:00）に相談できます。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）、パソコン
  • 事業系のごみ、リフォームなどで出た建築廃材
  • 処理困難物：土、石、消火器、自動車・バイクとその部品、石油・灯油、塗料類など（市では処理できないもの）

家電4品目は、市では収集しません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安・市の家電4品目のページ）。

急ぐときはたちむにぃ・リサイクルセンターへ持ち込む

  • 燃やせる粗大ごみ（木製の机・家具、ふとんなど）：クリーンセンターたちむにぃ（立川市泉町2,002、042-519-5319）。木製家具は金属を外し、木材・板は一辺1mくらいに切りそろえます。
  • そのほかの粗大ごみ（金属・プラスチックなど）：総合リサイクルセンター（立川市西砂町4-77-1、042-531-0950）
  • 受付：月〜金曜（祝日も受付、年末年始は休み）8:30〜12:00、13:00〜16:00。受付時間内に入場します。
  • 予約：要りません。処理券も要りません（総合リサイクルセンターはオンラインの事前受付も任意で使えます）。
  • 料金の目安：10kgにつき300円（10kgに満たない端数の扱いは市のページで確認）。2025年11月からキャッシュレス決済が使えます。
  • 持ち物と決まり：運転免許証・国民健康保険証・直近の公共料金の領収証・消印付きの郵便物など、市内に住んでいるとわかる物。持ち込めるのは本人だけで、本人が行けないときは先にごみ対策課（042-531-0950）へ電話します。分別していないと断られることがあります。

引越しなどで一度にたくさん出るときは、市の処理施設へ持ち込むよう市が案内しています。持ち込む前の準備は持ち込みの準備と持ち物へ。

立川市に引っ越してきた人へ

立川市の公式ページでは、引越しや転入について次のように案内しています（2026年10月30日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しなどで一度にたくさんのごみが出るときは、市の処理施設へ持ち込むよう市が案内しています。
  • 市の施設へ持ち込めるのは市民本人だけで、運転免許証や消印付きの郵便物など、市内に住んでいるとわかる物が必要です。
  • 粗大ごみの収集は、市内に住む人が家庭で使っていた物に限られます。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。立川市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。家庭のごみを運べるのは市区と市区の許可業者だけです（ぼったくりの実例と見分け方）。

立川市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、立川市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
