堺市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、堺市の公式ページをもとにまとめました。

2026年10月31日に堺市の公式ページで確認・料金や日数は目安です

堺市の粗大ごみは、最大辺か径がおおむね30cmを超える物が対象で、手数料は400円〜2,000円です。収集日は申し込んだ日の翌週になり、曜日は選べません。引越しの日が決まったら早めに申し込みましょう（堺市の公式ページより）。

堺市のポイント
  • 対象：最大辺か径がおおむね30cmを超える家具・家庭用品など
  • 料金：400円・800円・1,200円・1,600円・2,000円
  • 申し込み：インターネット（24時間）、電話（平日9時〜17時、土曜9時〜13時）
  • 収集：申し込んだ日の翌週。朝9時までに出す
  • 急ぐとき：クリーンセンターへ予約して持ち込める（粗大ごみは100kgまで1,700円）

申し込み方法

  • インターネット（24時間・メンテナンス時を除く）：堺市 粗大ごみインターネット受付。電話でしか受け付けない品目もあります。
  • 電話：粗大ごみ受付センター 0120-00-8400（携帯・IP電話は 06-6485-5048）。月〜金 9:00〜17:00、土 9:00〜13:00（祝日も受付、日曜・年末年始は休み）

月曜・火曜と祝日の次の日は電話がつながりにくくなります。支払い（処理券の購入かキャッシュレス決済）は収集日の前日までにすませます。

料金の目安と払い方

料金品目の例

2026年10月30日に堺市 主な粗大ごみ処理手数料品目例で確認。料金は目安です。

  • 「粗大ごみ処理券」を、セブン-イレブン、ファミリーマート、ミニストップ、デイリーヤマザキ、ローソン、堺市農業協同組合などの取扱所で買います。再発行・払い戻しはできません。
  • ネットで申し込んだ人は、キャッシュレス決済でも払えます。

出し方

  • 処理券に収集日と受付番号を書き、品物ごとに見やすいところに貼ります。キャッシュレスで払った人は、収集日と受付番号を書いた紙を貼ります。
  • 収集日の朝9時までに出します。収集は9時以降で、時間は選べません。立ち会いはいりません。
  • 雨や風の日も、貼り紙がはがれないようにします。申し込んだ物とわからないと収集されません。
  • 茶わんや花瓶などの「不燃小物類」は無料で、申し込めば45リットル以下の袋3袋まで出せます。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • バイク・原付、ピアノ、タイヤ、バッテリー、消火器、プロパンガスボンベ、薬品・塗料、瓦や土砂・建築廃材など
  • 事業所から出た物

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ運びます（指定引取場所の検索・料金の目安）。くわしい品目は市の公式ページで確認してください。

急ぐときはクリーンセンターへ持ち込む

  • 持ち込み先：クリーンセンター臨海工場（堺区築港八幡町1番地70、072-282-7400）、クリーンセンター東工場（東区石原町1丁102番地、072-252-0815）
  • 受付：月〜土（祝日も可）。臨海工場は8:30〜16:30（11:30〜12:15を除く）、東工場は12:15〜16:30。
  • 予約：家庭ごみは事前予約が必要です（堺市電子申請システム。ネットが使えないときはクリーンセンター管理課 072-355-3174）。予約なしでは受け入れません。
  • 料金：破砕施設を使うごみ（粗大ごみなど）は1回100kgまで1,700円、こえると10kgごとに170円。そのほかのごみは100kgまで1,100円、こえると10kgごとに110円。車1台ごとに現金で払います。
  • 運転免許証など住所・氏名がわかる書類と、ごみが出た場所の住所がわかる書類が必要です。家庭ごみは2トン車までで、市内で出たごみに限ります。

出典：堺市 クリーンセンター清掃工場への持込み・堺市 粗大ごみの申込み

堺市に引っ越してきた人へ

堺市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • クリーンセンターへの家庭ごみの持ち込みは事前予約制で、堺市内で出たごみに限られ、持ち込む人の住所・氏名とごみが出た場所の住所がわかる書類が必要です。
  • 引越業者や片付け業者など許可のない業者による持ち込みは認められず、自分で運べないときは臨時的ごみ収集や粗大ごみ収集を使うよう案内されています。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。堺市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

堺市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、堺市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
