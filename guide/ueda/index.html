上田市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、上田市の公式ページをもとにまとめました。

2026年11月8日に上田市の公式ページで確認・料金や日数は目安です（運営者と調べ方）

上田市には、申し込んで家まで取りに来てもらう粗大ごみの収集はありません。木の家具・布団・畳などの燃やせる粗大ごみは、上田クリーンセンターか丸子クリーンセンターへ自分で持ち込みます。金属・ガラス・プラスチックでできた燃やせない粗大ごみは市では受け入れていないので、民間の処理業者に相談します（上田市の公式ページより）。

上田市のポイント
  • 申し込み：市の粗大ごみ収集はない。集積所にも出せない
  • 燃やせる粗大ごみ：上田・真田地域は上田クリーンセンター、丸子・武石地域は丸子クリーンセンターへ平日に持ち込む
  • 料金：持ち込みは20kgまで400円、20kgを超えると10kgごとに200円
  • 燃やせない粗大ごみ（金属・ガラス・プラスチック製の物）や家電：市の受け入れ施設はなく、民間の処理業者へ
  • 引越しのときは、指定袋に入るごみを1回4袋まで集積所に出せる（ふだんは2袋まで）
申し込み料金出し方家電4品目持ち込み

申し込み方法

上田市では、粗大ごみを市に申し込んで収集してもらうしくみはありません。指定袋に入らない物は粗大ごみになり、ごみ集積所には出せません。

  • 燃やせる粗大ごみ：自分でクリーンセンターへ持ち込みます。決まった7種類（下の「急ぐときは」を参照）以外の物を持ち込むときは、前もって相談するよう市は案内しています。
  • 燃やせない粗大ごみ・運べないとき：市が許可した一般廃棄物の処理業者・収集運搬業者に、直接頼みます（有料。許可業者の名簿）。料金は業者に直接聞きます。
  • 問い合わせ：上田市 廃棄物対策課 0268-22-0666

料金の目安と払い方

出し方料金
クリーンセンターへの持ち込み（20kgまで）400円
クリーンセンターへの持ち込み（20kgを超えた分）10kgごとに200円
燃やせない粗大ごみ（民間の処理業者）業者に確認

料金は目安です。2026年11月8日に上田市 粗大ごみ、大量のごみで確認。

料金は重さで決まります。市の指定袋に入れる必要はなく、指定袋に入れて持ち込んでも料金は変わりません。上田市では粗大ごみ処理券（シール）は使いません。クリーンセンターでの払い方は市のページに書かれていないので、廃棄物対策課で確かめてください。

処理券（シール）の買い方

出し方

  • 指定袋に入る大きさのごみは、燃やせるごみ・プラマーク付プラスチック・燃やせないごみとして集積所に出せます。1回に出せるのは2袋まで、1袋10kgまでです。
  • 布団（中が綿や羽毛の物）は、折りたたんでひもでしばり、指定袋（大）を1枚巻きつければ、燃やせるごみの日に1回1枚まで出せます。雨の日は出せません。2枚以上のときはクリーンセンターへ持ち込みます。
  • 木のたんす・机・いすは、金属やプラスチックなどの燃やせない部分を外してから持ち込みます。
  • 品目ごとの出し方は、市のごみの分別帳か、ごみ分別アプリ「さんあ～る」で確かめます。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）。指定袋に入る大きさでも市では回収しません。
  • パソコン（メーカーのリサイクルへ）
  • 金属・ガラス・プラスチック製の粗大ごみ、家電製品（クリーンセンターでも受け入れず、民間の処理業者へ）
  • 新聞・雑誌・段ボールなどリサイクルできる紙類（クリーンセンターでは受け入れず、資源物回収所かウィークエンドリサイクルへ）

家電4品目は、市では回収しません。買い替えるお店・買ったお店に引き取ってもらいます。買ったお店が分からない、閉店した、遠いときは、市の家電リサイクルのページにある一般廃棄物収集運搬業者に頼みます（市の家電リサイクルのページ・指定引取場所の検索・料金の目安）。

上田市の粗大ごみの持ち込み（急ぐとき・上田クリーンセンター）

引越しなどでたくさん出たごみは、種類ごとに出し先が分かれます。指定袋に入るごみは、袋に「引越し」と書けば1回4袋まで集積所に出せます（1袋10kgまで。4袋を超えると、全部の袋が収集されません）。それより多いときや、袋に入らない燃やせる物は、クリーンセンターへ持ち込みます（引越し等で出るごみの出し方）。

  • 場所：上田・真田地域（と青木村）の人は上田クリーンセンター（上田市天神3-11-31、0268-22-0666）。丸子・武石地域（と長和町）の人は丸子クリーンセンター（上田市腰越399-1、0268-43-2131）。
  • 受付：上田クリーンセンターは8:30〜11:45、13:00〜16:00。丸子クリーンセンターは9:00〜11:30、13:00〜16:00。土曜・日曜・祝日は持ち込めません。
  • 持ち込める物：家庭から出た物だけ。原則、枝木・板切れ（長さ150cm以内、太さ8cm以内）、木の机・いす、布団類（1回10枚まで）、純毛のカーペット・じゅうたん、木のたんす、畳（1回10枚まで）、燃やせるごみに分けた大量ごみの7種類です。燃やせない物は受け入れません。
  • 予約：予約が要るとは書かれていません。7種類以外の物は前もって相談します。
  • 料金：20kgまで400円、20kgを超えると10kgごとに200円。
  • 持ち物：本人確認の書類が要るかは市のページに書かれていないので、廃棄物対策課で確かめてください。段ボール箱に入れて運んだときは、箱は持ち帰ります。
  • 上田クリーンセンターに持ち込んだ剪定枝は、裏手の施設でチップにします。受付で渡される札を持って行けば、料金は燃やせるごみと同じです。

まだ使える物は、市のエコ・ハウス（0268-23-5144）の不用品交換情報で、ゆずる相手を探すこともできます（不用品交換情報）。

上田市に引っ越してきた人へ

上田市の公式ページでは、引越しや転入について次のように案内しています（2026年11月8日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 上田市には市の粗大ごみ収集がなく、指定袋に入らない物は集積所に出せません。
  • 引越しのときは、袋に「引越し」と書けば、指定袋に入るごみを1回4袋まで集積所に出せます（ふだんは2袋まで）。
  • 木の家具や布団などの燃やせる粗大ごみはクリーンセンターへ平日に持ち込み、金属やプラスチックの物は民間の処理業者に頼みます。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。上田市の分け方に従って出します。

引越しで間に合わないとき

市の収集では引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

上田市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、処分代がかからず値段がつくこともあるので、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらい、値段がつかなければ断って上田市の粗大ごみに切り替えます（どのお店とも提携していません）。

セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどの買取チェーンが出張買取をしています。
