高崎市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、高崎市の公式ページをもとにまとめました。

2026年10月30日に高崎市の公式ページで確認・料金や日数は目安です

高崎市では、長い辺が60cm以上か、重さが10kg以上の物、指定袋に入れて口がしばれない物が粗大ごみです。収集の料金は1品520円で、1回5点まで。申し込みは電話だけで、収集日は地域ごとに曜日が決まっています。自分で運べば1回100kgまで無料で持ち込めます（高崎市の公式ページより）。

高崎市のポイント
  • 対象：長い辺60cm以上、または10kg以上の物、指定袋で口がしばれない物（長い辺はおおむね180cmまで）
  • 料金：1品520円（粗大ごみ処理券1枚）。処理券は全国のセブン-イレブンでも買える
  • 申し込み：地域ごとの受付先へ電話（月〜金曜 9:00〜17:00）。インターネット受付の案内はなし。1回5点まで
  • 収集：地域ごとに決まった曜日に、道路に面した敷地の中（玄関先など）へ
  • 急ぐとき：高浜クリーンセンターなどへ持ち込める。1回100kgまで無料

申し込み方法

  • 電話：高崎・倉渕・群馬・新町・吉井・榛名・箕郷の地域ごとに、市が案内する受付先へ電話します（市のページの受付先の一覧）。受付は月〜金曜 9:00〜17:00（土日祝日は休み）。どこに電話すればよいかわからないときは、高崎市 一般廃棄物対策課 027-321-1253 に聞けます。

インターネットでの受付は、市のページに案内がありません。1回に出せるのは5点までです。希望の日に収集できないこともあるので、引越しが決まったら早めに電話しましょう。収集日は地域ごとに決まっています。

  • 高崎・群馬・吉井地域：水曜（高崎地域は土日に収集することもあり）
  • 新町地域：第2・第4金曜
  • 榛名地域：第1・第3水曜
  • 箕郷地域：木曜の午後と金曜の午後
  • 倉渕地域：受付先と相談して決めます

料金は目安です。2026年10月30日に高崎市 粗大ごみの出し方で確認。料金は1品につき処理券1枚（520円）です。2019年10月より前に買った500円・510円の券も使えます。

  • 「粗大ごみ処理券」（全市共通）は、全国のセブン-イレブン（2024年12月1日から）、市役所の一般廃棄物対策課・清掃管理課、各市民サービスセンター、各支所の市民福祉課、新町クリーンステーション、吉井クリーンセンターなどで買えます（セブン-イレブンでの販売）。
  • 払い戻しはできません。キャッシュレスで払えるかどうかは、市のページに書かれていません。

処理券（シール）の買い方

出し方

  • 処理券を1品に1枚貼ります。
  • 収集の日に、玄関先など道路に面した敷地の中に出します。何時までに出すかは市のページに書かれていないので、申し込みのときに確かめてください。
  • 電気カーペットのコントローラーは切り取って、燃やせないごみか小型家電の回収ボックスへ出します。

出せない物と家電4品目

  • テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機、エアコン（家電リサイクル法の対象）、パソコン・ディスプレイ
  • スプリング入りマットレス、ピアノ、大型物置、タイヤ、消火器、ガスボンベ、耐火金庫、オートバイなど（市では収集・処理ができないもの）。お店か専門の処理業者に頼みます。スプリング入りマットレスは、スプリングとそれ以外に分ければクリーンセンターなどに持ち込めます。
  • 事業所から出るごみ

家電4品目は、粗大ごみとしても燃やせないごみとしても出せず、クリーンセンターへも持ち込めません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安・市の家電4品目のページ）。自分で運べないときは、リサイクル券を用意したうえで市の清掃管理課に運搬を頼むこともでき、運搬料金は1個3,140円です。

急ぐときは高浜クリーンセンターへ持ち込む

  • 持ち込み先：高浜クリーンセンター（高崎市高浜町252番地1、027-344-2530）。ほかに吉井クリーンセンター・新町クリーンステーションにも粗大ごみを持ち込めます。
  • 受付時間：月〜金曜 8:30〜16:45（土日祝日・年末年始は休み。高浜は昼休みなし）。混んでいると時間がかかるので、余裕をもって行きましょう。
  • 予約：要るかどうかは市のページに書かれていません。持ち込む前に施設へ確かめてください。
  • 料金の目安：1回100kgまで無料。100kgを超えた分は1kgにつき15円と消費税相当額です（10円未満は切り捨て）。
  • 持ち物と決まり：本人か同居の家族が持ち込みます。名前と住所がわかる本人確認書類（運転免許証・マイナンバーカードなど）が要ります。高崎市の外で出たごみは持ち込めません。不燃・粗大ごみは、燃えるごみと下ろす場所が違います（家庭ごみを持ち込む際のお願い（PDF））。

引越しで一度にたくさん出て自分で運べないときは、市の清掃管理課に収集を頼めます（電話 027-323-0972、月〜金曜 8:15〜17:00、祝日・年末年始は休み）。平日だけの収集で、ごみは前もって分けておきます。料金の目安は45リットル袋で約12袋3,300円・約24袋6,600円・約40袋11,800円で、当日に現金で払います。市が案内する「引越ごみ」の許可業者に頼むこともできます（市の引越し等の多量ごみのページ）。

高崎市に引っ越してきた人へ

高崎市の公式ページでは、引越しや転入について次のように案内しています（2026年10月30日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しで一度にたくさん出て自分で運べないときは、市の清掃管理課に電話で収集を頼めます（45リットル袋約12袋で3,300円が目安、当日現金払い）。市の「引越ごみ」の許可業者に頼むこともできます。
  • クリーンセンターへ持ち込むときは、本人か同居の家族が、名前と住所がわかる本人確認書類を持っていきます。住所が違うときは追加の書類が要ります。
  • 高崎市の外で出たごみは、高崎市民のものでも持ち込めません。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。高崎市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 受付に電話して、早い収集日がないか聞く
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

高崎市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、高崎市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
