仙台市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、仙台市の公式ページをもとにまとめました。

2026年10月30日に仙台市の公式ページで確認・料金や日数は目安です

仙台市の粗大ごみは、一番長い部分がおおむね30cmを超え、重さ100kg以下の物が対象です。手数料は400円〜1,600円（スプリングマットレスは3,000円）で、ネットで初めて申し込む人は収集日の7日前が締め切りです。引越しの日が決まったら早めに申し込みましょう（仙台市の公式ページより）。

仙台市のポイント
  • 対象：一番長い部分がおおむね30cmを超え、重さ100kg以下の家庭の物
  • 料金：400円・800円・1,200円・1,600円、スプリングマットレスは3,000円
  • 申し込み：インターネット、電話（平日9時〜17時）
  • 出し方：収集日の朝8時30分までに、指定された場所へ
  • 急ぐとき：今泉・葛岡・松森の各工場へ自分で持ち込める（100kgまで1,500円）

申し込み方法

  • インターネット：仙台市 粗大ごみインターネット受付。品目別表にある品目だけ申し込めます。
  • 電話：粗大ごみ受付センター 022-716-5301（月〜金 9:00〜17:00。祝休日も受付、土日と12月29日〜1月3日は休み）

締め切りは、ネットの初回（または登録内容を変えるとき）が収集日の7日前の24時、2回目以降で変更がなければ収集日の2日前の17時です。電話は収集日の1か月前から2日前まで受け付けます。変更・取り消しは収集日の前日17時まで。申し込みが多いと、次の収集日に回ることがあります。

料金と払い方

手数料は品目や大きさで400円・800円・1,200円・1,600円、スプリングマットレスは3,000円です。品目ごとの金額は五十音で引くワケ方事典で確かめられます。

  • 「粗大ごみ手数料納付券」は400円券と3,000円券（スプリングマットレス専用）の2種類。800円なら400円券を2枚使います。
  • 青いシールが目印のお店で買えます。セブン-イレブン、デイリーヤマザキ、ファミリーマート、ミニストップ、ローソンなど。
  • 払い戻しはできないので、申し込みが終わってから買います。台紙（領収書）は収集が終わるまで取っておきます。

2026年10月30日に仙台市 粗大ごみの出し方で確認。料金は目安です。

出し方

  • 納付券に受付番号かお名前を書いて、粗大ごみに貼ります。券がない・足りない・名前などがないと収集されません。
  • 収集日の当日の早朝から8時30分までに、受付センターが指定した場所に出します。立ち会いはいりません。前の日に出すのはやめましょう。
  • 雨の日も原則として収集します。ストーブの電池や灯油、植木鉢の土、電気スタンドの電球などは取り除きます。
  • 家の中からの運び出しは原則していません（65歳以上や障がいのある人だけの世帯など、条件つきで対応あり）。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • 家庭のパソコン、そのほか市で収集しない物（市の相談先のページ）
  • 会社やお店など、事業所から出た物

家電4品目は、買い替えるお店・買ったお店に引き取ってもらうか、郵便局でリサイクル料金を払い込んで指定引取場所へ運びます（指定引取場所の検索・料金の目安）。市が案内している市内の指定引取場所は次のとおりです。受付時間は行く前に確かめてください。

急ぐときは工場へ持ち込む・臨時ごみを頼む

  • 自己搬入：今泉工場（若林区）、葛岡工場（青葉区）、松森工場（泉区）に自分で運べます。平日9:00〜16:15（土日祝・年末年始は休み）。料金は車1台1回100kgまで1,500円、100kgをこえると10kgごとに150円。現金だけで、納付券は使えません。
  • 受付で「廃棄物搬入承認申請書」を書きます。持ち込めるのは自分や家族のごみだけで、荷下ろしも自分でします。
  • 臨時ごみ：引越しや大掃除でたくさん出るときは、区の環境事業所か市の許可業者に収集を頼めます。料金は粗大ごみの品目別料金＋その他のごみ10kgごとに260円＋収集手数料1回1,000円で、収集のときに現金で払います（申込先の一覧）。

出典：仙台市 ごみの自己搬入・仙台市 粗大ごみの出し方

仙台市に引っ越してきた人へ

仙台市の公式ページでは、引越しや転入について次のように案内しています（2026年10月30日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しや大掃除でごみが多量に出るときは、ごみ集積所には出せず、区の環境事業所か市の許可業者に「臨時ごみ」として収集を頼みます（その他のごみ10kgごとに260円＋収集手数料1回1,000円＋粗大ごみの品目別料金、現金払い）。
  • 工場への自己搬入は自分や家族のごみに限られ、受付で廃棄物搬入承認申請書を書きます。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。仙台市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。家庭のごみを運べるのは市区と市区の許可業者だけです（ぼったくりの実例と見分け方）。

仙台市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、仙台市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
