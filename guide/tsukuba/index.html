つくば市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、つくば市の公式ページをもとにまとめました。

2026年10月30日につくば市の公式ページで確認・料金や日数は目安です

つくば市では、いちばん長い辺が50cm以上の物が粗大ごみです。料金は大きさで決まり、400円・800円・1,200円の3段階です。インターネットは収集日の5日前、電話は2日前までに申し込むので、引越しが決まったら早めに予約しましょう（つくば市の公式ページより）。

つくば市のポイント
  • 対象：いちばん長い辺が50cm以上の物（200cmを超える物・70kg以上の物は収集しない）
  • 料金：長い辺の長さで400円・800円・1,200円（処理券は400円券1種類）
  • 申し込み：インターネット（収集日の5日前まで）、電話（2日前まで）。1回5点まで
  • 収集：収集日の朝8時までに指定の場所へ。立ち会いは要りません
  • 急ぐとき：つくばサステナスクエア（クリーンセンター）へ予約なしで持ち込める（10kgごとに130円）

申し込み方法

  • インターネット（収集日の5日前まで）：つくば市 粗大ごみインターネット受付。収集日の5日前（土日を含む）までに申し込みます。送信した時点では仮の受付で、確認のメールが届いて決まります。職員から電話で確かめることもあります。
  • 電話：つくば市粗大ごみ受付センター 029-860-2984（月〜金曜 8:45〜16:30、年末年始は休み）。収集日の2日前まで。

1回の収集日に5点まで申し込めます。6点以上は電話で相談するか、何回かに分けるか、クリーンセンターへ持ち込みます。インターネットで申し込んだ人は、今回の収集が終わってから2日後に次の申し込みができます。申し込みの前に、品物の名前・数・いちばん長い辺の長さを測っておきましょう。TX沿線の一部の地区は、ネットで住所を入れるときに注意があります（市のインターネット受付の案内）。

料金の目安と払い方

大きさ（いちばん長い辺。丸い物は直径）料金
50cm以上120cm未満400円
120cm以上180cm未満800円
180cm以上200cm以下1,200円
棒状の物（直径10cmまで・長さ150〜200cm）400円

料金は目安です。2026年10月30日につくば市 粗大ごみの大きさと料金で確認。大きさに関係なく料金が決まっている品目もあるので、申し込みのときに確かめてください。重ねて厚さ10cmまでの板は1点として出せます。

  • 料金は予約のときに決まります。「粗大ごみ処理券」（1枚400円）を、決まった金額の分だけ市内の取扱店で買います（処理券の取扱店）。払い戻し・再発行・使い回しはできません。収集が終わるまでレシートをとっておきましょう。
  • インターネットで申し込んだ人は、2026年6月15日からクレジットカード（VISA・MasterCard・JCB・AMERICAN EXPRESS・Diners Club）かPayPayでも払えます。電話で申し込んだ人は処理券で払います。

処理券（シール）の買い方

出し方

  • 処理券に受付番号（4桁）を書き、品物の見えやすいところに貼ります。インターネットで申し込んだ人には、受付番号がメールで届きます。
  • 収集日の朝8時までに、指定された場所に出します。家の外で、道路から見える場所です。立ち会いは要らず、収集の時間は選べません。
  • いちばん長い辺が50cm未満の物（40リットルの袋に入るくらい）は、素材ごとに燃やせるごみ・燃やせないごみで出します。

出せない物と家電4品目

  • テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機、エアコン（家電リサイクル法の対象）とパソコン
  • いちばん長い辺が200cmを超える物、70kg以上の物、市が処理が難しいとしている物
  • 事業所から出るごみ、建築・解体で出たごみ

家電4品目は、大きさに関係なく市では収集しません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安・市の家電4品目のページ）。

急ぐときはつくばサステナスクエアへ持ち込む

  • 場所：つくばサステナスクエア（クリーンセンター）、つくば市水守2339（029-867-1379）
  • 予約：要りません。ごみは分けてから持っていきます。
  • 受付時間：月〜金曜 8:30〜16:30、土曜 8:30〜11:30。日曜は休み。祝日の受付時間は市のページで書き方が分かれているので、施設に確かめてください。
  • 料金の目安：家庭のごみは10kgごとに130円。車ごと量って計算します。処理券は要りません。
  • 持ち物：運転免許証など、名前と住所がわかるもの。今の住所が書いていないときは、公共料金の領収書なども持っていきます。つくば市内で出たごみだけ受け付けます。
  • 家電4品目・パソコン・産業廃棄物は持ち込めません。

引越しや家の片付けで一度にたくさん出るごみも、自分で持ち込めます。運べないときは、市の一般廃棄物収集運搬の許可業者に頼めます（料金は業者ごと。市が案内する許可業者の一覧）。

つくば市に引っ越してきた人へ

つくば市の公式ページでは、引越しや転入について次のように案内しています（2026年10月30日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しや家の片付けで一度にたくさん出るごみは、つくばサステナスクエア（クリーンセンター）へ自分で持ち込めます。運べないときは市の一般廃棄物収集運搬の許可業者に頼めます。
  • 持ち込むときは運転免許証などで名前と住所を確かめます。今の住所が書いていないときは公共料金の領収書なども持っていきます。
  • つくば市内で出たごみだけ持ち込めます。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。つくば市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

つくば市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、つくば市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
