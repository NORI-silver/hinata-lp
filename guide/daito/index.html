大東市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、大東市の公式ページをもとにまとめました。

2026年10月31日に大東市の公式ページで確認・料金や日数は目安です

大東市の粗大ごみは、令和5年（2023年）7月1日の申し込み分から一部有料になりました。料金は大きさで300円か600円の2段階で、1回に出せるのは6点までです。引越しで多く出るときは、有料の「臨時（引越）ごみ」で自宅まで取りに来てもらえます（大東市の公式ページより）。

大東市のポイント
  • 料金の目安：一番長い辺が30cm以下は無料、30cmを超え3辺の合計が3m未満は300円、3辺の合計が3m以上は600円（令和5年7月からの料金）
  • 申し込み：粗大ごみ受付センターへ電話。インターネットは、以前に電話で申し込んだことがある人が対象
  • 点数：1回6点まで（2020年更新の市のページ）。7点以上は臨時（引越）ごみ（有料）か焼却場へ持ち込み
  • 出す時刻：収集日の朝7時まで
  • 持ち込み：東大阪都市清掃施設組合（焼却場）へ予約して持ち込み。10kgあたり90円

申し込み方法

  • 電話：大東市粗大ごみ受付センター 072-870-5381（受付時間は市のページで確認）
  • インターネット（電子申請）：大東市 粗大ごみインターネット予約受付。市のページでは、以前に電話で申し込んだことがある人が対象と案内されています。初めての人や市内で引越した人は、まず電話で申し込みます。

申し込むときは、品目・大きさ・個数を先に確かめておきます。電話で申し込んだときの名前・住所・電話番号と合っていないと、インターネットでは予約できません。1回に出せるのは6点までです（2020年11月更新の市の申込方法のページ）。

料金の目安と払い方

大きさ料金
一番長い辺（直径）が30cm以下無料
30cmを超え、3辺（幅・奥行き・高さ）の合計が3m未満300円
3辺の合計が3m以上600円

料金は目安です。2026年10月31日に、市の粗大ごみの有料化についてと、市の広報の特集（令和5年7月からの有料化のお知らせ（PDF））で確認。品目ごとの金額は市のページの表で確かめてください。

  • 電話で申し込んだ人は、市内の指定取扱店で「大東市証紙（粗大ごみ処理券）」（1枚300円）を買います。300円の物は1枚、600円の物は2枚です。処理券（シール）の買い方
  • インターネットで申し込んだ人は、電子決済（クレジットカード、PayPay、au PAY、d払い）も選べます。期限内のキャンセルや減額の変更は自動で返金されます（市のキャッシュレス決済のページ）。

出し方

  • 収集日と受付番号を処理券（無料の物は不要の紙）に書き、品物に貼ります。電子決済の人は、収集日・名前・受付番号を書いた紙を目立つところに貼ります。
  • 収集日の朝7時までに、指定された場所に出します。
  • 紙が貼られていない、品目が申し込みと違う、手数料が足りない物は収集されません。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • 1回に7点以上、または一人で持てない重さの物は、ふつうの粗大ごみには出せません（臨時（引越）ごみか持ち込み）。
  • 事業所から出るごみ

家電4品目は、市では収集しません。買い替えるお店・買ったお店に引き取ってもらうか、郵便局で家電リサイクル券を買って指定引取場所へ自分で運びます（指定引取場所の検索・料金の目安）。市の案内は家電リサイクル法対象4品目の処分方法にあります。

急ぐときは焼却場へ持ち込む

  • 持ち込み先：東大阪都市清掃施設組合（焼却場）
  • 予約：必要です。072-975-5341に電話して予約します。
  • 料金の目安：10kgあたり90円。
  • 持ち込める物：市で収集できるごみと同じです。
  • 住所・受付時間・持ち物は市のページに書かれていません。予約のときに確かめてください。

引越しや大掃除で一度にたくさん出るときは、有料の臨時（引越）ごみを、大東市環境室（環境事業グループ）072-870-9265に予約します。自宅まで取りに来てもらえます。料金の目安は、軽トラック1台分で最大6,000円、2トントラック1台分で最大12,000円、パッカー車1台分で最大18,000円です。持ち込みの準備と持ち物

大東市に引っ越してきた人へ

大東市の公式ページでは、引越しや転入について次のように案内しています（2026年10月31日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • ふつうの粗大ごみは1回6点までで、7点以上は有料の臨時（引越）ごみか焼却場への持ち込みになります。
  • 引越しで多量に出るごみは、大東市環境室に臨時（引越）ごみを予約すると自宅まで収集に来てもらえます（軽トラック1台分で最大6,000円など）。
  • インターネットの予約は以前に電話で申し込んだ人が対象で、市内で転居したときはもう一度電話で予約します。
  • 東大阪都市清掃施設組合（焼却場）へは予約して持ち込めて、料金は10kgあたり90円です。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。大東市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 7点以上は環境室に電話して、有料の臨時（引越）ごみを頼む
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

大東市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらうと、処分代がかからず、値段がつくこともあります。値段がつかなければ断って、大東市の粗大ごみに切り替えます。セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどのチェーンが出張買取をしています（どのお店とも提携していません）。
