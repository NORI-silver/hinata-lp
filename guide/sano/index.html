佐野市の粗大ごみの出し方と料金

申し込み方法、料金と払い方、出し方、持ち込み先、家電4品目、引越しで急ぐときの方法を、佐野市の公式ページをもとにまとめました。

2026年11月8日に佐野市の公式ページで確認・料金や日数は目安です（運営者と調べ方）

佐野市の粗大ごみは、ごみステーションには出せず、市の窓口で申請して手数料を先に払い、玄関先まで集めてもらう戸別訪問収集です。料金は重さで決まり、40kgまでの物は1点1,650円、40kgを超える物は1点3,300円。収集は佐野地域が毎週木曜日、田沼・葛生地域が毎週土曜日で、毎週火曜日までの申し込み分をその週に集めます。申し込みは窓口だけで、引越しなどで一度にたくさん出る粗大ごみは収集の対象外です。そのときは、みかもクリーンセンターか葛生清掃センターへ自分で運びます（10kgにつき220円。佐野市の公式ページより）。

佐野市のポイント
  • 対象：指定袋（中）に入りきらない物（掃除機と高さ75cm以下の扇風機などは除く）。引越し・大掃除で一度に多量に出る物は戸別収集の対象外
  • 料金：40kgまで1点1,650円、40kg超1点3,300円（収集運搬とごみ処理の手数料の合計）。申請のときに先に払う
  • 申し込み：市民課・田沼行政センター・葛生行政センター（平日）、みかもクリーンセンター・葛生清掃センター（月〜土曜）の窓口。8:30〜17:15
  • 収集：佐野地域は毎週木曜、田沼・葛生地域は毎週土曜の13:00〜16:00。毎週火曜までの申し込み分をその週に集める
  • 持ち込み：みかもクリーンセンター（佐野地域）・葛生清掃センター（田沼・葛生地域）へ月〜土曜。10kgにつき220円。初回は「ごみ搬入届出証」が要る
申し込み料金出し方家電4品目持ち込み

申し込み方法

  • 窓口（平日）：佐野市役所 市民課、田沼行政センター・葛生行政センター（月〜金曜 8:30〜17:15）
  • 窓口（土曜も）：みかもクリーンセンター（佐野市町谷町206-13）・葛生清掃センター（佐野市あくと町3360）（月〜土曜 8:30〜17:15）

どこかの窓口で「粗大ごみ収集申請」をして、手数料を先に払います。インターネットや電話で申し込めるとは、市のページに書かれていません。電話で申し込めるかどうか、窓口での払い方（現金のほかに使えるもの）、1回に出せる点数の上限は、環境政策課（0283-23-8153）に確かめてください。

市のごみ分別の手引きでは、毎週火曜日までに申し込んだ物を、その週の収集日（佐野地域は木曜、田沼・葛生地域は土曜）に集めると案内しています。年末は申し込みの締め切りが早まることがあり、市のページでお知らせしています。

料金の目安と払い方

品目料金
粗大ごみの戸別収集（重さ40kgまで、1点）1,650円
粗大ごみの戸別収集（重さ40kgを超える物、1点）3,300円
センターへの持ち込み（10kgにつき）220円

料金は目安です。2026年11月8日に佐野市 粗大ごみの出し方・ごみ分別の手引きで確認。

戸別収集の料金は、品目ではなく1点ごとの重さで決まります。家まで運ぶ収集運搬手数料と、ごみ処理手数料を合わせた金額です（税込）。たんす・ベッド・布団・じゅうたん・自転車・学習机・いすなどは、ごみ分別の手引きで粗大ごみに分けられています。処理券（シール）を店で買う仕組みではなく、申請した窓口で前払いします。

重い物を1点ずつ出すと、持ち込み（10kgにつき220円）のほうが安くなることがあります。運べる車があるときは、持ち込みとくらべてみてください。

出し方

  • 粗大ごみは、収集日に玄関先などに出しておきます。収集は13時から16時の間です。
  • 粗大ごみは、ごみステーションには出せません。分解してもステーションには出せません。
  • 掃除機と扇風機（高さ75cm以下）、傘・箒・杖・柄の長い掃除用具・バット・蛍光灯を除き、指定袋（中）に入りきらない物は粗大ごみになります。
  • 布団・座布団・じゅうたんも、指定袋（中）に入りきらなければ粗大ごみです。
  • まだ使える物は、市が連携している「おいくら」（買取店への一括見積もり）で売る方法や、市の「不用品登録制度」で譲る方法もあります。

出せない物と家電4品目

  • エアコン、テレビ、冷蔵庫・冷凍庫（保冷庫・保温庫も）、洗濯機・衣類乾燥機（家電リサイクル法の対象）
  • パソコン（メーカー回収か、市が協定を結ぶリネットジャパンの宅配便回収へ）
  • 渦巻き状（コイル状）のスプリングが入ったソファ・座椅子・マットレス（市では処理できません。購入先に相談）。スプリングの入っていないソファ・マットレスは粗大ごみで出せます。ベッドもスプリング入りマットレスは処理できません
  • ピアノ、オルガン・電子ピアノ（1m四方以上）、消火器、タイヤ、自動車・バイクとその部品、バッテリー、石膏ボード、断熱材、ステンレスの流し台、陶器の便器、農機具、冷媒を使う冷風扇・除湿機など
  • 会社・商店・農業などから出る事業ごみ（ステーションには出せません）

家電4品目は、粗大ごみでは出せません。買い替えるお店・買ったお店に引き取ってもらうか、市内の協定協力店（佐野市特定家電引取協力店会）に頼むか、郵便局でリサイクル料金を払って指定引取場所（栃木市岩舟町）へ自分で運びます。リサイクル券を用意すれば市へ頼むこともでき、そのときは収集運搬手数料（戸別訪問収集で1台2,200円、センターへ持ち込めば1台1,100円）がかかります（指定引取場所の検索・料金の目安・市の家電4品目のページ）。

佐野市の粗大ごみの持ち込み（急ぐとき・みかもクリーンセンター・葛生清掃センター）

引越しや大掃除で一度にたくさん出る粗大ごみは、戸別収集では出せません。市の清掃センターへ自分で運ぶか、市の一般廃棄物収集運搬許可業者に有料で頼むよう、市が案内しています（粗大ごみの出し方）。住んでいる地域で持ち込む先が決まっています。

  • 佐野地域：みかもクリーンセンター（佐野市町谷町206-13、0283-23-8153）
  • 田沼・葛生地域：葛生清掃センター（佐野市あくと町3360、0283-86-4351）
  • 受付：月〜土曜 9:00〜11:50、13:00〜16:30（一部の祝日と年末年始は休み）。土曜や祝日は混むことがあり、市の収集車が優先されます。
  • はじめての人：どちらかのセンターで「ごみ搬入届出」を申請し、「ごみ搬入届出証」を受け取ってから持ち込みます（初回だけ。受付は月〜土曜 8:30〜17:15）。申請のときは免許証や公共料金の領収書など、今の住所が分かる物を持っていきます。
  • 予約：要るかどうかは市のページに書かれていません。心配なときはセンターに電話で確かめてください。
  • 料金：10kgにつき220円（税込）。払い方は市のページに書かれていないので、センターに確かめてください。
  • 持ち物：ごみ搬入届出証（免許証などを見せるよう言われることがあります）。
  • 運ぶのは自分の世帯の人か許可業者だけで、友人・知人や許可のない業者に運んでもらうことはできません。粗大ごみ以外は分別して透明・半透明の袋か指定袋に入れ（レジ袋は不可）、係員の指示した場所で自分で降ろします。車は4トン車（ショートボディ）以下です。
  • 相続した家の残置物や、市外に住む人が佐野市内の実家のごみを運ぶときは、ごみを出す場所の住所と今の持ち主が分かる物を持っていきます。前もってセンターに問い合わせるとスムーズです。

佐野市に引っ越してきた人へ

佐野市の公式ページでは、引越しや転入について次のように案内しています（2026年11月8日確認）。最後の3つは、どの市区でも気をつけたいことです。

  • 引越しや大掃除で一度にたくさん出る粗大ごみは、市の戸別訪問収集の対象外です。みかもクリーンセンター（佐野地域）か葛生清掃センター（田沼・葛生地域）へ自分で運ぶか、市の許可業者に頼みます。
  • センターへはじめて持ち込むときは「ごみ搬入届出証」が要ります。今の住所が分かる免許証や公共料金の領収書などを持っていきます。
  • コイル状のスプリングが入ったソファ・マットレスは、市では処理できません。購入先に相談します。
  • 申し込みは、住み始めてから新しい住所で。住む前に申し込めるかは受付で確かめてください。
  • 処理券やシールは自治体ごとに別の物です。前の自治体で買った券は使えません。
  • 段ボールや梱包材は粗大ごみではありません。佐野市の分け方に従って出します。

引越しで間に合わないとき

収集の予約が引越しに間に合わないときは、次の順番で考えます。

  1. 予約ページをこまめに見る（キャンセルで早い日が空くことがあります）
  2. まだ使える物は買取に出す（下の買取店へ）
  3. 自家用車があれば、上の持ち込み先へ
  4. それでも無理なら新居へ運ぶ（損しやすい理由も読んでください）

品目ごとの出し方と、ほかの市区との料金の比べ方：布団・ソファ・マットレス・ベッド・自転車

「無料で回収します」という巡回・チラシの業者に頼むのはやめましょう。お金を払ってごみの回収を頼めるのは、市区か、市区の許可業者だけです（家電4品目は買ったお店・買い替えるお店でも引き取れます）（ぼったくりの実例と見分け方）。

佐野市の近くのリサイクルショップ（買取）

まだ使える家具や家電は、処分代がかからず値段がつくこともあるので、出張査定・キャンセル無料をはっきり書いているチェーンの買取店に見てもらい、値段がつかなければ断って佐野市の粗大ごみに切り替えます（どのお店とも提携していません）。

セカンドストリート、ハードオフ・オフハウス、トレジャーファクトリーなどの買取チェーンが出張買取をしています。
