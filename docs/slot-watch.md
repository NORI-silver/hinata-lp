# 空き枠見張り PoC（2026-10-31〜2026-11-14・無料・記録だけ）

¥500 の空き枠通知を売る前に、「キャンセルなどで早い収集日が本当に出てくるか」を2週間記録して確かめる。お客さんへの通知・課金はまだしない。

## 何を見ているか

- **千葉市**（sodai-web.jp）の公開ページ「収集日の確認（最短収集日）」 https://www.sodai-web.jp/sodai/shortest_calendar.na?id=09
  - ログイン・メール登録・申し込みは一切しない。だれでも見られる確認用ページを、区（6区）ごとに読むだけ。
  - 1日3回（8:23・12:23・19:23 JST）。1回で6区、区ごとに5秒あける。画像・フォント・翻訳スクリプトは読み込まない。
  - User-Agent に `hinata-slot-poc/1.0 (+https://hinata.shiokonbu.com/about/)` と名乗る。
- 「最短収集日が前の回より早くなった」＝空きが出た、と数える（`tools/slot_watch/summary.py`）。

## 見ていないところと理由（2026-10-31 確認）

- **e-tumo（ecolife.e-tumo.jp：杉並・港・大阪市など）**：空き日は「規約に同意 → メール確認」のあとでないと見えない。規約の禁止事項に「本サービスを申請等以外の目的で使用すること」があるので、見張りには使わない。
- **www2.sodai-web.jp（荒川・葛飾・江東・目黒・三鷹・武蔵野・中野・墨田）**：作業環境から接続を許可していない。千葉市で結果が出てから広げるか決める。

## 動かし方

```
node tools/slot_watch/sodai_web.js /mnt/project-files/slot-watch/chiba.csv   # 1回分を追記（約2分）
python3 tools/slot_watch/summary.py /mnt/project-files/slot-watch/chiba.csv  # 集計
```

記録はリポジトリではなくプロジェクトの共有フォルダ `slot-watch/chiba.csv` に置く（サイトには出さない）。

## 判断の目安（11/14）

- 2週間で「早まった回」が区あたり数回以上 → ¥500 の通知に価値がある。特商法表記・規約・Stripe・LINE の準備へ。
- ほとんど出ない → 通知は売らない。診断（無料）と持ち込み・買取の案内に集中。

## 診断での表示（2026-10-31〜）

Nori さんの判断で、千葉市の診断では区を選ぶとその時点の最短収集日を出す（`backend/reviews.gs` の `slot_`、同じ公開ページを1回読むだけ）。区ごとに30分はキャッシュ、1日300回まで。取れなかったときは「予約サイトで確かめてください」と出し、目安の日数で判定する。
