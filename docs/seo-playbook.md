# SEOの定期作業（hinata.shiokonbu.com）

定期のSEOエージェント（Claude の定期実行。週2回）と、手で頼まれたAIのための手順です。
文言・表示のルールは `AGENTS.md` が正本。ここに書いていないことは `AGENTS.md` に従います。

## 目的

「粗大ごみ 引越し 間に合わない」「粗大ごみ 出し方 ＋市区名」で検索した人に見つけてもらい、診断を使ってもらうこと。
数を増やすために中身の薄いページは作らない。**ほかのページに載っていない、確かめた情報**を足す。

## 1回の作業の流れ

1. `git log` と開いている PR を見て、前回までにやったこと・まだマージされていない PR を確かめる。同じ内容の PR を重ねて出さない。開いている SEO の PR が2本以上あるときは新しい PR を出さず、終わる。
2. `python3 tools/seo_check.py .` を実行する。NG があれば、それを直すのが最優先。
3. Search Console のデータが使えるとき（SEOツールが hinata.shiokonbu.com に対応したら）は、直近28日の表示回数・クリック・順位を見て、表示はあるのにクリックが少ない検索語から手を付ける。使えないときは、メインキーワードで検索して上位3件を読み、うちのページに足りない情報を探す。
4. 改善を **1回に1つ** 選んで、ブランチを切って PR を出す（`main` には直接入れない。マージは Nori さん）。PR の説明には「何を・なぜ（見た数字や上位ページ）・確かめた公式ページと確認日」を書く。
5. やったこと・やらなかったことを `docs/seo-log.md` の先頭に1〜3行で足す（PR に含める）。

## やってよい改善（上から優先）

- `tools/seo_check.py` の NG・WARN を直す。
- タイトル・description・見出しの言い回しを、検索語に合わせて直す（文字数は AGENTS.md の目安）。
- FAQ を足す（本文と FAQPage の両方。実際に検索されている疑問だけ）。
- 対応している市区の情報を、**公式サイトで確かめて** 足す・直す（受付方法、料金、持込先）。確認日を本文に書き、`index.html` の確認日もそろえる。確かめられないものは「市の公式サイトで確認」と書く。
- 市区ごとのページ（例：`/yokohama/`）を足すのは、そのページにしか載っていない確かめた情報が十分あるときだけ。足したら `sitemap.xml` に入れ、トップからリンクする。

## やらないこと

- 料金・日数を言い切る（必ず「目安」）。公式で確かめていない数字を書く。
- 提携していない個人店の名前・電話番号、根拠のない実績や件数。
- 決済・申し込みボタン、「通知します」と言い切る文言（課金方針が決まるまで）。
- 家電4品目を市区で回収できるように読める書き方。
- 外部サービスへの登録・送信、`main` への直接の反映。

## Nori さんにしかできないこと

Search Console の操作（プロパティ追加・サイトマップ送信・サービスアカウントの追加）だけ。それ以外は聞かずに進める。
