# 診断フォームの点検（粗大ごみフォーム点検エージェント）

トップの診断フォーム（`index.html` の `Q`・`judge`・`itemOptions`）を直したら、この手順で点検する。
Claude は `.claude/agents/form-reviewer.md` のエージェントに任せられる。ほかのAIや人はこのファイルの手順をそのまま行う。

最初の点検：2026-10-31（Nori「ユーザーの入力に沿って判定できるか、品目の選び方はそれでいいか、デフォルトでソファなど選ばなくていい、シンプルで網羅的に、競合に見劣りしないか」）。

## 1. 自動チェック（必ず）

```
node tools/form_check.js .
```

実際にブラウザで入力して、判定と使いやすさを確かめる。NG を0にする。見ていること：

- 初期状態で品目・お住まいが勝手に選ばれていない／入力前は品目カードを出さない
- 質問は6つ以内、1問のチップは12個以内（お住まいを除く）
- 家電4品目は市区の回収が×。「テレビ台」「布団乾燥機」など名前が似た物を家電4品目にしない
- パソコン・ピアノ・タイヤ・消火器など、粗大ごみで出せないことが多い物を「市の回収◎」にしない
- 一覧にない物を入れても出し方の候補が出る
- 日数・車で判定が変わる（間に合う→市の回収、間に合わない＋車あり→持込）
- 住所の入力（佐倉市ユーカリが丘、大阪市北区）、`/?city=` の引き継ぎ
- 金額に「目安」、スマホ幅で横にはみ出さない、チップが押しやすい高さ

判定のルールを足したら、ここにもチェックを足す。

## 2. 目で見る点検（観点）

スマホ幅（390px）とPC幅でスクリーンショットを撮り、次を見る。

| 観点 | 見ること |
|---|---|
| 入力に沿った判定 | 入れた物・日・車・お住まいが結果に全部反映されるか。使われない質問はないか |
| 品目の選び方 | よく出る物が1タップで選べるか。少なすぎ（家具・家電のような大きな分類だけ）も、多すぎ（30個並ぶ）もだめ。一覧にない物は自由入力・写真で足せるか |
| 迷わない | 何から入れればよいかわかるか。初期値が勝手に入っていないか。結果が出る前に何が足りないかわかるか |
| 正しさ | 家電4品目、パソコン（メーカー回収）、処理困難物、目安と公式リンク。AGENTS.md の「文言・表示のルール」 |
| 速さ | 入れてから結果まで、スクロールせずに次が見えるか |

## 3. 競合と比べる

公式（横浜市・川崎市などの粗大ごみ受付ページ）と、民間の比較・回収サイト（おいくら、くらしのマーケット、ジモティー など）のフォームを見て、表にする。

- 何を聞いているか（質問の数・順番）、品目の選び方（分類→品目／検索／写真）、結果に何が出るか
- このサイトのほうが劣っている点だけを直す候補にする。民間の「無料見積もり」に誘導する作りはまねしない（このサイトは診断のみ・送信なし）

## 4. 報告

点検の結果は、NG・指摘ごとに「どこ」「何が困るか」「直し方」を書き、直したら `node tools/form_check.js .` と `python3 tools/seo_check.py .` を通してから PR を出す。
